## 二、缺口：反覆出現、框架沒有對應說法或判讀問題

### G1　「下沉」：最大的一群，框架沒有區辨問題（約 32 句）
腿沉、臀沉、像翹翹板、像綁鉛塊、浮不起來。同樣是「沉」，分類者把它們散配到 free.L0／L1／L2／L3 和 C 型共五格，**說明框架對「沉」沒有能分開候選的問題**。
原話自己其實帶著區辨線索：
- 靜態就浮不起來：「我從來沒辦法停在原地浮著」#44 → L0／L1 或硬體
- 靜態是平的，一動才沉：「流線型和靜止時腿是平的，但一開始游臀部就下沉」#93 → L2 以上
- 一換氣或一划手才沉：「手放身邊臀部勉強能浮；一加上划水和旋轉就整個垮掉」#252、「手一抬準備空中回手，臀部下背就開始往下沉」#176 → C 型候選
- 器材拿掉才沉：#96

**建議的區辨問題**：「不動、只漂著的時候也沉嗎？如果不沉，是從哪個動作開始沉？」

### G2　「喘」：框架完全沒有這個字（約 28 句）
喘不過氣、吸不到氣、游 25 公尺就累垮。分類者在 fitness 與 L0／L2 之間搖擺。原話裡有強烈的反證線索：
- 「我跑個 5–10 公里都沒問題，但 25 公尺就累垮」#189
- 「同時戴浮板跟呼吸管並刻意放慢，我可以不停游 100 到 200 公尺」#122
- 「我雖然一直在換氣，卻覺得根本吸不到氣」#70

這些都指向「不是體能，是吐氣或換氣」。**建議的區辨問題**：「陸上有氧運動會這樣喘嗎？戴呼吸管慢游會不會比較好？」

### G3　情境性恐懼（約 28 句）
開放水域、深水、看到水底、比賽、離開牆或浮具。框架只在 free.L2 stagnation 提到「換氣恐慌」，L0 把安全感當成「呼吸規律的輸出」。見衝突 K1。

### G4　翻滾轉身頭暈（6 句）
「翻轉本身沒問題，但做完會頭暈」#90、「暈到差點吐在池子裡」#234。free.L1 有一段前庭適應的說明，但說這些話的人都已經會翻滾轉身，不在 L1。分類者一半配 L1、一半配 fitness，兩邊都不對。需要決定這類歸到哪裡（前庭或暈動，屬非感知分類？）。

### G5　仰式鼻子進水（5 句）
「蹬牆時我沒有主動吸氣，但鼻子每次都會灌滿水」#230。框架沒有「鼻」字；back.L0 直接沿用自由式。

### G6　器材依賴（約 6 句）
「脫掉蛙鞋之後，感覺身體完全沒記住蛙鞋的動作」#258、「不穿蛙鞋就立刻喘不過氣」#117。這是「器材遮蔽感知」的直接自述，框架裡沒有對應的判讀。

### G7　冷水／防寒衣胸悶（4 句）
「水超冷，胸口整個緊到不行」#64、「防寒衣在胸口那邊超緊的」#67。被配到 L0，應屬環境或器材，非感知分類裡缺這一類。

（疼痛 11 句、浮力過強壓不下去 3 句都已經被正確標成 pain_injury／hardware，不列缺口。）

## 三、衝突：原話跟框架的假設對不上

**K1　恐懼跟 L 級脫鉤**
「我泳池可以游 3000 公尺，但就是怕湖跟開放水域」#224。框架把安全感放在 L0（呼吸規律建立後自然產生），但這位泳者技術已經在高 L 級，恐懼只在特定情境出現。真實語料顯示恐懼有一大塊是**情境觸發、跨 L 級**的，不全是 L0 未完成。

**K2　「肩膀累」不能單獨判成 A 型**
Q3 的 A 選項是「肩膀和上臂特別累，**但游的感覺不太對**」。但：
- 「抓水感覺越好，反而越覺得上半身沒力氣可以一直划」#198：抓水進步，肩膀負荷反而增加，這是好轉的訊號，不是手感缺失。
- 9 句吻合的原話大多只說「肩膀累」，沒有後半句。

後半句才是區辨關鍵；只有「肩累」時，候選應包含 fitness 與正在進步中的 L3／L4。

**K3　「下沉」被當成單一現象**（同 G1）
同一句「我的腿一直會往下沉」被配到 back.L1／L3／L4 三格（#49），代表目前框架讀到這句話時無從排除任何一格。

### 可做 1：「沉」的分流（草案，等使用者審）
1. 吸飽氣、不動地漂（水母漂）會浮嗎？不浮 → **硬體邊界（體組成）**，不用感知訓練硬解。
2. 會浮，但腿慢慢往下掉 → **下半身偏重（浮心與重心距離）**，靠姿勢補償（手前伸、頭與胸的位置），屬 L1 漂浮感知。
3. 靜態是平的，一動才沉 → 問「從哪個動作開始沉」：換氣（`prob.free.head-lift-breath`）、看前方（`free.tech.18`）、划手（`free.tech.23` 因果鏈）。
4. 身體繃、手腳一直想往上找水面 → **緊張**（`psych.arousal.muscle_tension_loop`／`psych.fear.freeze_reflex`），先處理安全感。

### 可做 2：「喘」的四線分流（在既有三線前加一條）
1. 陸上爬樓梯、快走也喘？→ **一般體能**（很少運動）。
2. 陸上不喘，水裡喘；戴呼吸管慢游明顯好轉？→ **換氣感知未建立**（憋氣、抬頭找氣）。
3. 技術沒問題，長距離後段才喘到掉速？→ **呼吸肌**。
4. 某件事之後才喘（一下水、嗆到、比賽、深水）？→ **喚醒或恐懼**，接心理層。

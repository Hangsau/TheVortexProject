四類結構性缺陷代號（用於旗標說明段）：
- **缺陷 1**：池畔可見方向 vs 解剖學動作混用
- **缺陷 2**：缺「上舉平面」欄位（含必要外旋漏標）
- **缺陷 3**：以手掌／腳掌空間朝向反推關節旋轉
- **缺陷 4**：把「踝」當單一關節（距小腿／距下／橫跗未分層）

### BR-2 下肢打水（蛙式蹬夾腿 / whip kick）

#### BR-2-1 收腿期（Recovery）

| ID | 原文主張 | 類 | 旗標 |
|---|---|---|---|
| BR-21 | 收腿期：髖關節屈曲 | A | |
| BR-22 | 收腿期：髖關節外展 | A | |
| BR-23 | 收腿期：髖關節外旋（大腿分開、腳跟往臀部方向拉） | A | ⚠︎ |
| BR-24 | 收腿期：膝關節屈曲（最大可達約 130°～140°） | B | |

⚠︎ BR-23：「髖關節外旋（讓腳跟往臀部方向）」——腳跟往臀部方向拉是膝屈曲動作，不是外旋的描述。「大腿分開」是外展的描述，亦與外旋混列。外旋方向本身尚有爭議（見自我驗證段，詳後），此條以「收腿期外旋」暫記，旗標待裁決。分類上「腳跟往臀部方向拉」屬膝屈曲描述被歸入髖旋轉，是原文混淆兩個動作，**疑似缺陷 3（以可見動作反推關節旋轉）**。

⚠︎ BR-26：「踝關節外翻（eversion）」——外翻（eversion）發生在距下關節（subtalar joint）和橫跗關節（transverse tarsal joint），不是距小腿關節（踝關節真正的活動度只有背屈/蹠屈）。原文把複合足部動作稱為「踝關節外翻」是單一關節誤稱。**疑似缺陷 4（把「踝」當單一關節）**。

⚠︎ ST-02：「些微外旋（讓上臂能貼緊耳側而不聳肩）」——在超流線（肩最大屈曲）姿勢下加外旋，目的是讓上臂通過大結節不撞頂撞肩峰弓，這與 Neumann 的第六運動學原理（上舉必然伴隨外旋）一致。命名方向正確，但原文用「讓上臂貼緊耳側而不聳肩」當理由，這是功能性結果描述（C 類）而非解剖機制。A 類部分（外旋方向）可裁決，C 類部分（為什麼需要外旋）不由教科書裁決。建議拆為兩條，但本批維持單條並旗標。

⚠︎ ST-06：「肩胛骨後傾（posterior tilt）」——後傾是肩胛骨相對胸壁的矢狀面旋轉（下角遠離胸壁、上角靠向胸壁），Neumann 第五章有描述此動作。然而超流線手臂最大屈曲位時，同時存在上迴旋（ST-05）和後傾（ST-06），兩者的相互關係在 Neumann 中有特定論述（上舉末端肩胛骨動作是複合的）。原文用語本身不算錯，但「後傾」在日常教練語言中不常見，裁決時須確認教科書術語定義與原文一致。**分類待確認（A，裁決時標準化定義）**。

## 六、優先人工審閱條目

以下條目建議在 P2 機械裁決前，先由人工確認方向：

1. **BR-28（翻腳期：踝外翻、腳尖朝外）** — 同時命中缺陷 3 + 缺陷 4，是本批解剖爭議最大的單條。「腳尖轉向外側」牽涉髖／膝／距下／橫跗多個關節，無法以單一「踝外翻」概括。此條若直接用教科書裁決，踝外翻（eversion）本身是可定義的動作，但原文所指的實際位置不只是距下關節，整個推論鏈是有問題的。

2. **BR-44 / BR-45（蛙式肩關節前脫位宣稱）** — 高風險傷害宣稱，原文 cite index 格式已知不可解析。在追溯到 PubMed 原始文獻前，此內容不得寫入 Vortex 任何公開層教材。

3. **BR-46 / BR-47（蛙式膝：膝外翻應力→蛙式膝）** — 傷害宣稱同上。「外翻應力存在」的解剖推論部分（可能 A 或 B）與「因此引發蛙式膝」的流行病學宣稱（C）混合，必須拆分。

4. **ST-13 / ST-16（水下海豚打腿的體位問題）** — 原文說「動作模式與蝶式相同」，但未明確區分俯臥出發 vs 仰躺轉身後的體位差異。仰式轉身後做水下海豚踢，若沿用蝶式命名（俯臥），髖屈伸方向全部翻轉（缺陷 1 風險），可能複製 BK-30/BK-33 的錯誤。

5. **BR-30（蛙式翻腳期髖旋轉爭議）** — 自我驗證段已有兩派說法對立（收腿期外旋 vs 膝屈曲時內旋），原文誠實保留爭議。裁決時此條不可强行收斂；建議保留爭議並列各方立場，對應協議 §3 型 5（真實學界分歧）。

6. **BF-23（蝶式移臂期：伸展→外展→屈曲）** — 第三次重演缺陷 2（繼 FR-23、BK-04）。此條裁決結果幾乎可以直接預測為「修正」（缺上舉平面欄位 + 缺外旋），但蝶式無軀幹旋轉輔助，移臂的力學負荷分佈可能與自由式不同，須確認是否影響關節動作命名本身。

### m.1｜mechanism.summary
- 原文：「俗稱「蝶泳下背症候群」」
- 類型：2（待查）
- 問題：英文文獻常見對應是 swimmer's low back / dolphin kick-related LBP，「蝶泳下背症候群」作為獨立「症候群」未見於 ICD-10 或主流 review。標「俗稱」需先證明它真的是社群慣用詞，否則等於自創詞掛上「俗稱」。
- 建議：〔待查證〕若無文獻，改寫為「本文以「蝶／蛙過伸型下背痛」描述，避免讀者誤以為有正式症候群命名」；若有文獻支持，補上出處。
- 查法：請 Claude 對 src.pmc11531034、src.pmc3435931、PMID 31141446 全文 grep「swimmer's back / dolphin / butterfly / syndrome / low back syndrome」；另於 PubMed、Google Scholar 搜 "butterfly swimmer low back syndrome" 回報有無任何命中。
- 信心：低（直覺，待驗）

### m.2｜mechanism.summary

- 類型：6
- 問題：「炎性 vs 肌肉韌帶型」是臨床鑑別分型，layer 同時為 `public + clinical`，會直接落到公開欄位；等於對一般讀者（家長、成人初學者、鐵人）做臨床分型判讀。
- 建議：公開版摘要改寫為「以腰椎過伸負荷為主的下背不適」，把「關節突關節炎性／肌肉韌帶型」分型移到 diagnostic 子樹。
- 查法：請 Claude grep repo 內所有 `layer: public` 條目的 `mechanism.summary`，確認是否有其他條目也在公開層做臨床分型。
- 信心：中

### t.1｜mechanism.trigger_phase
- 原文：「蝴蝶踢下踢、蛙泳回腿、水中伸展姿勢、腳踢板」
- 類型：3
- 問題：「水中伸展姿勢」範圍過寬——任何水中挺腰伸展（扶牆伸展、水中瑜珈、暖身挺腰）都會被讀者歸類進來，與另三項具體動作並列會誤導讀者把「任何水中拉伸」都視為風險動作；同時讀者無法判斷自己算不算此條目標。
- 建議：把「水中伸展姿勢」明確化或刪除；若要保留，寫為「蛙泳/蝶式後的水中過度挺腰伸展（例：扶牆挺腰放鬆）」，並標來源。
- 查法：請 Claude 對 src.pmc11531034與 src.pmc3435931 grep「stretch / stretch / lumbar extension in water」，確認是否有文獻把「水中伸展」列為獨立 trigger phase。
- 信心：低（直覺，待驗）

### ep.1｜epidemiology.prevalence
- 原文：「蝶式下背痛 33.3–50%、蛙泳 22.2–47%；有下背痛者蝴蝶踢時腰椎過伸角度顯著較大、髂腰肌彈性模量更高；精英泳者脊椎退化率 68% vs 休閒 29%」
- 類型：4
- 問題：四組數字（33.3、50、22.、47、68、29）給到小數級，但本檔 flags.pending_verification 自承「68% 退化率原始研究為摘要/二手」、「女性差異數字為摘要/二手」；以二手轉述的精確小數配 🟡 + evidence_grade B，是確定性標記與內容強度不對齊的典型。
- 建議：把 prevalence 改為區間 + 二手註記，例如「蝶泳下背痛二手回顧發生率約 22–50%（精確值與樣本數待 W3 補原文）」；68%/29% 改成「精英泳者脊椎退化率高於休閒族群（具體數字與樣本待 W3 核對二手鏈）」。
- 查法：請 Claude 對 src.pmc11531034、src.pmc3435931 全文 grep「33.3 / 50 / 22.2 / 47 / 68 / 29 / degenerative / recreational / shear wave / elastography」，回報每個數字是否真在 PDF 出現、出現句意、樣本 N、信心區間；同步交叉比對 PMID 31141446 的設計（族群、量測儀器）。
- 信心：中

### ep.2｜epidemiology.evidence_grade
- 原文：「evidence_grade: B」
- 類型：4
- 問題：本條目核心引用為 narrative review（src.pmc11531034）+ narrative review（Wanivenhaus 2012），非 RCT、亦非系統性回顧，且主要數字屬二手轉述；B 級一般代表「單一 RCT 或多個同質非隨機研究」，與實際證據強度不對齊。
- 建議：evidence_grade 改 C；certainty 從 🟡 改 🟠（教練觀測＋二手），並在 caveat 內補一句「敘述回顧＋二手轉述，缺高品質 RCT」。
- 查法：請 Claude 確認 src.pmc11531034 是否確為 narrative review（標題／作者結論段）；對照 repo 其他條目 evidence_grade 標記慣例。
- 信心：中

### rf.1｜risk_factors[5]

### mgt.1｜management.acute
- 原文：「訓練調整(停蝶/蛙/腳踢板)、關節鬆動、軟組織治療、NSAIDs」
- 類型：3 + 6
- 問題：layer 同時為 `public + clinical`，NSAIDs 與「關節鬆動」會直接出現在公開欄位。NSAIDs 是含 GI／AKI 風險的處方級藥物，自行服用會蓋掉椎弓解離／感染等 red flag 疼痛訊號；「關節鬆動」在無專業操作下對關節突出關節發炎有惡化風險。對家長／成人初學者尤其危險。
- 建議：公開版只留「訓練調整」；NSAIDs 與「關節鬆動、貼紮」整段移到 diagnostic 子樹，或加警語「NSAIDs 須由臨床人員處置；徒手治療須由合格人員執行」。
- 查法：請 Claude grep repo 內其他 `layer: public` 條目 management.acute，統計 NSAIDs／關節鬆動出現次數；確認本檔是否已有 diagnostic 子樹版本。
- 信心：高

### p.2｜prevention[4]
- 原文：「分散筆畫避免長時間單一蝶/蛙」
- 類型：2
- 問題：「筆畫」在中文通常指書法／繪畫的筆觸，游泳文獻標準用語為「分散泳式」「分散訓練量」「stroke variety」；此處用詞不屬於社務／教練常用語。
- 建議：改為「分散泳式，避免長時間單一蝶／蛙訓練」。
- 查法：請 Claude grep repo 內所有 prevention / training advice 段，搜尋「分散筆畫 / 分散泳式 / stroke variety」，統計兩種用法的相對出現次數與慣例。
- 信心：低（直覺，待驗）

### 1｜demands[entry]/action_ids + demands[wall-push-off]/action_ids
- 原文：「- movement.action.shoulder-complex.horizontal-adduction」（兩段 action_ids 並列）
- 類型：2
- 問題：水平內收（horizontal adduction）的標準解剖定義是肱骨在 90° 外展位於水平面上往中線移動；兩處相位（entry 與 wall-push-off）雙臂都在頭頂過頂位，對應的是肩屈曲加內收，不是水平面內收。兩段 description 把這兩個相位定位為「肩複合體上舉＋肩胛上迴旋＋肩胛前伸」合成，未提及水平內收。
- 建議：待查證。若詞彙表內 horizontal-adduction 對過頂位有特殊定義則保留；否則改用 [shoulder-complex.adduction] 或在 description 補一句水平內收的位置前置條件。
- 查法：請 Claude grep 詞彙表 movement.action.shoulder-complex.horizontal-adduction 的動作定義；對比 Neumann 2017 對 horizontal adduction 的章節描述；回查兩段 description 是否仍把過頂位用水平內收描述。
- 信心：中

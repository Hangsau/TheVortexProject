### demands[movement.demand.udk.up-kick.hip-extension-prone]｜public.description
- 原文：「跨過髖與膝兩個關節的股直肌被拉長後，被動張力會把髖伸展可用量壓回接近中位。」
- 類型：2
- 問題：被動不足（passive insufficiency）確實會在膝屈曲下縮減髖伸展可用量，但典型量化是「縮減 30–40°」，而非「壓回接近中位」；膝關節活動範圍在游泳上踢時也並非完全屈曲。整句把效應寫得太絕對。
- 建議：〔待查證 Neumann 2017 中 hip extension with knee flexion 的實際 ROM 數值後改寫〕；保守寫法：「膝屈曲下髖伸展可用量明顯縮減，是否壓回接近中位依個體與膝屈曲角度而定。」
- 查法：請 Claude grep `src.neumann-2017` 的引用段落（或 README 內登記的章節），找出 hip extension 受 rectus femoris 被動不足影響的具體 ROM 數字；同時驗證「膝屈曲時 hip extension 可用幅度典型減少量」是否落在 30–40°。
- 信心：中

### demands[movement.demand.udk.up-kick.hip-extension-prone] 與 hip-flexion-supine｜public.description
- 原文（俯臥）：「膝只有屈曲一個方向可用，踝的蹠屈同理」
- 原文（仰躺）：「膝只有屈曲方向可用，踝的蹠屈同理」
- 類型：1
- 問題：字面讀為「膝只能屈曲」，但同段 action_ids 同時列出 `movement.action.knee.extension`（膝伸展）。這在因果內自打嘴巴；作者似乎是想說「膝的屈曲–伸展軸命名不隨體位翻轉」，但寫成「只有屈曲一個方向可用」會被讀成膝不能伸展。
- 建議（俯臥）：「膝的屈曲–伸展軸命名不隨體位翻轉，踝的蹠屈–背屈同理」
- 建議（仰躺）：「膝的屈曲–伸展命名不隨體位翻轉，踝的蹠屈–背屈同理」
- 查法：請 Claude grep `knee.flexion|knee.extension|action_ids` 確認兩個條目都列了膝伸展；同時 grep `只有屈曲一個方向可用` 看是否還有其他段落共用同樣誤寫。
- 信心：高

### demands[movement.demand.udk.up-kick.hip-flexion-supine]｜evidence_profile / source_ids
- 原文：「evidence_profile: anatomy」「source_ids: src.neumann-2017, src.veiga-2022」
- 類型：4
- 問題：evidence_profile 標為 anatomy，但 src.veiga-2022 經此筆本身的 diagnostic 描述為「水下蝶式打腿運動學系統性回顧」（實證文獻，不是純解剖）。若 Veiga 2022 是系統性回顧，evidence_profile 至少需加入 synthesis 或標明 empirical成分；純 anatomy 會誤導讀者以為本筆僅依解剖推導。
- 建議：將 evidence_profile 改為「anatomy + empirical」，或拆成兩個條目區分命名層與運動學層。
- 查法：請 Claude 在 source registry 中 grep `veiga-2022`，確認其文獻類別（系統性回顧 / 期刊 / 樣本數）；再依此決定 evidence_profile 應改成什麼。
- 信心：中（待 src.veiga-2022 真實文獻類型確認）

### demands[movement.demand.udk.up-kick.hip-flexion-supine]｜diagnostic.assessment_note
- 原文：「Veiga 等人 2022 的水下蝶式打腿運動學系統性回顧明文寫出，仰躺體位的打腿運動學決定因素沒有任何研究處理過，該回顧納入的 25 篇有 23 篇只做俯臥」
- 原文：「該回顧轉引的兩篇俯臥／仰躺對照本身也不一致（一篇報告兩體位的打腿參數無統計差異，另一篇報告仰躺的垂直振幅與踝伸展較大）」
- 類型：5
- 問題：四個具體文獻細節——25 篇、23 篇只做俯臥、兩篇對照的相反結論——都是直接轉述自 Veiga 2022；任何一項錯就會讓「升級路徑關閉」的整個推理失效。這是本筆全部升級判定的基礎，沒有原文查核就不能採。
- 建議：保持現狀直到驗證；驗證後若發現數字有出入，必須改寫。
- 查法：請 Claude 找 Veiga et al. 2022 的系統性回顧原文（PubMed / Scopus 搜 "Veiga underwater dolphin kick systematic review 2022"），核對：①總納入篇數；③僅俯臥的篇數；②兩篇對照文獻的存在與結論是否如描述所寫。
- 信心：高（必須驗證）

### demands[movement.demand.starts-turns.flight.posture-attainment-without-trajectory-change]｜action_ids
- 原文（description）：「action_ids 列出 hip.abduction，是為了表明髖維持在不外展的位置，不能把這個 ID 讀成此相位要做髖外展」
- 類型：4
- 問題：用 `hip.abduction` 的 ID 來表示「不外展的維持」，但 ID 名稱字面就是「做髖外展」。對讀者與下游 consumer（搜尋、join、圖表生成）來說，這個 ID 會被當成「此相位發生髖外展」，與作者本意相反；同段也提到「庫內沒有登錄 hip.adduction，本筆不為此新造動作」，等於承認這個欄位的語意被反讀。屬於標記系統與意圖不符。
- 建議：改用一個語意對得起「維持不外展」的 ID（例如新增 `hip.maintain-adducted` 或在 action_status 設為 `not-occuring` 的標記），而不是借用相反方向的 ID。
- 查法：請 Claude grep `hip.abduction` 在整個 demands 樹的用法，確認這個「反讀」約定是否在其他條目也被採用；若只有此筆，問題更明顯；若多筆共用，則是 schema 設計問題，需另議。
- 信心：中

### demands[movement.demand.starts-turns.flight.posture-attainment-without-trajectory-change]｜muscle_roles 對 action_ids
- 原文（action_ids）：`movement.action.ankle-foot.plantarflexion` 與 `movement.action.hip.abduction`
- 原文（muscle_roles）：僅列 `movement.muscle.trunk-sagittal-controllers`
- 類型：1
- 問題：action_ids 列出踝蹠屈與髖外展兩個關節動作，但 muscle_roles 完全沒有對應的踝蹠屈肌或髖外展肌。對比其他筆（supine 1:1 對應、palm-orientation 大致對應），本筆的肌肉清單與動作清單脫鉤；讀者會以為踝與髖「零肌肉參與」，與 description 描述的「姿勢達成、收攏」矛盾。
- 建議：在 muscle_roles 補上踝蹠屈肌（`movement.muscle.ankle-plantarflexors`）與軀幹矢狀面控制肌以外的對應肌；若該筆的設計是不在 muscle_roles 放不在 description 提及的肌，則在 description 明確寫出這個約定。
- 查法：請 Claude grep 同檔其他 demands 條目，統計 action_ids 與 muscle_roles 的對應比例；並確認本檔 README 或 schema 文件是否規定 muscle_roles 只收 description 提到的肌。
- 信心：低（可能是 schema 約定）

### demands[movement.demand.starts-turns.set-position.coexisting-setups-not-a-single-posture]｜public.description
- 原文：「直臂與屈肘抓握的效率接近，肘可處於屈曲或接近伸展位，兩者並存，本筆不把其中一種寫成錯誤做法。」
- 類型：5
- 問題：「效率接近」是一個表現量比較聲稱，但本筆 source_ids 只有 Neumann2017（解剖）、Blanksby 2002、Yeadon et al. MDPI 2024。需驗證這項比較是否真的出自這三篇；若只是作者綜合，卻掛在 synthesis-inference 來源下，讀者會誤以為有文獻支持。
- 建議：若 Blanksby 2002 或 Yeadon 2024 沒直接比較直臂 vs 屈肘抓握的效率，改寫為「直臂與屈肘抓握在文獻中並未呈現單一較優做法，本筆並存保留」。
- 查法：請 Claude grep Blanksby 2002 與 Yeadon et al. 2024（MDPI）的摘要／結論段落，確認是否包含「grip efficiency」「straight-arm vs bent-arm grip」「elbow flexion」相關比較；如未涵蓋，則本句屬於過度歸屬。
- 信心：中

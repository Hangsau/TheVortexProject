### 1｜overview.premise_zh & overview.lines_zh[0] ⇄ grading.axes_zh[0]
- 原文：
  - overview/premise_zh：「跟『手感腳感』一樣按 L0–L6 分級」
  - overview/lines_zh[0]：「按 L0–L6 分級，內容不在本章而在 drills——自由式 breathing 類：FrBr1 韻律呼吸 / FrBr2 放鬆下沉 / FrBr3 連續涓流吐氣 / FrBr4 兩側換氣」
  - grading/axes_zh[0]：「感知線（在水裡）：按 **L0–L2** 分級。L0 水中連續吐氣 → L1 游進中持續吐氣 → L2 兩側換氣」
- 類型：1
- 問題：同一片段內 overview 兩處聲稱感知線分級是 L0–L6（七階），grading 卻定為 L0–L2（三階）。grading 補一句「兩者是同一條線的前後兩步，不是矛盾」試圖解套，但 overview 沒同步修正。讀者看到 overview 會以為感知線佔水感全程 7 階，看到 grading 才發現只佔前 3 階。另外 overview 列出 4 個 drill（FrBr1–FrBr4）對應 L0–L6 也不合——4 個 drill 對 7 階中間有缺。
- 建議：overview 兩處改為「按 L0–L2 分級（呼吸感知在水感框架只佔前 3 階；L3『對稱感知』由水感章節承接）」。drill 對照表保留四個，但說明 FrBr1 是 L0 前置、不佔階。
- 查法：grep `L0–L6` 與 `L0–L2` 在 framework.yaml 第 1 段的所有出現位置；請 Claude 確認 overview 與 grading 數字一致；順便查 FrBr1–FrBr4 的 L 級對照（drills 檔）。
- 信心：高

### 2｜overview.author_synthesis_zh & overview.plain_zh
- 原文：
  - author_synthesis_zh：「用憋氣訓練去解決一個其實是緊張的問題——**既無效又危險**」
  - plain_zh：「最常見的錯誤是用『憋氣練肺』去處理一個其實只是緊張的學生，既沒效果又很危險」
- 類型：3
- 問題：真正會致命的場景是「水下」憋氣（grading 自己寫「任何水下版本致命」並連到 breathing.safety.hypoxic_blackout）。陸上的 CO2 表（坐著做的呼吸肌訓練）有風險但非一概「危險」。overview 與 plain_zh 把「憋氣訓練」當單一概念、未區分水上／水下，也沒從公開欄位 cross-link 到 safety 子節。plain_zh 用「又很危險」一詞會讓一般讀者（成人初學、家長）把所有憋氣練肺（含陸上的 CO2 表、競賽前常見的閉氣練習）都視為高風險。
- 建議：author_synthesis_zh 改為「用憋氣訓練去解決一個其實是緊張的問題——既無效，又會把學生推向水下閉氣的黑暈風險（見 breathing.safety.hypoxic_blackout）」；plain_zh 改為「最常見的錯誤是用『憋氣練肺』去處理一個只是緊張的學生——沒效果；把它搬到水裡更會要命」。
- 查法：grep 「憋氣」/「危險」/「致命」在 framework.yaml 第 1 段與 safety.yaml 的共現；確認 overview 的 plain_zh 與 links 是否引用 breathing.safety.hypoxic_blackout。
- 信心：高

### 3｜overview.premise_zh, overview.author_synthesis_zh, grading.axes_zh[*], boundaries.excluded_zh[*], boundaries.principle_*
- 原文（代表性例子）：
  - overview/premise_zh 🔵：「Vortex 把呼吸拆成三條線」
  - overview/author_synthesis_zh 🔵：「三種的介入完全不同」
  - grading/axes_zh[0] 🔵：「按 **L0–L2** 分級」
  - grading/axes_zh[3] 🔵：「按 **練習量累積** 分級」
  - boundaries/excluded_zh[*] 🔵：「屬於一般健康 / 助眠脈絡，與游泳教學沒有可驗證的連結」
  - boundaries/principle_evidence_zh 🔵：「『情緒／喚醒改善的證據』不等於『游泳表現改善的證據』」
  - boundaries/principle_freediving_zh 🔵：「自由潛水是另一個脈絡」
- 類型：4
- 問題：🔵 定義為「物理／解剖推導（不需文獻）」。但上面這些是 framework 編輯決策（要分幾條線、按什麼軸分級）、scope 決定（收／不收什麼）、方法論原則（情緒證據 ≠ 表現證據），不能只靠物理或解剖推導得出。整個 boundaries entry（含 excluded 與兩條總則）全標 🔵 尤為離譜——「與游泳教學沒有可驗證的連結」是缺口判斷、不是物理事實；標 🔵 等於在說這個缺口是「不需文獻」就成立的。grading.axes_zh[2]「任何水下版本致命」是個安全宣稱，混了生理（anoxia → blackout）與「任何」這個全稱量詞，🔵 也不適合。
- 建議：
  - 「Vortex 把呼吸拆成三條線」、「按 L 分級」、「按 累積量 分級」、「三種介入完全不同」→ 🟠（教練觀測／框架決策）
  - 「呼吸肌是可被阻力訓練的骨骼肌」→ 保留 🔵
  - 「與游泳教學沒有可驗證的連結」→ 🟡（缺口判斷需文獻）或 🟠
  - 「情緒 ≠ 表現」、「自由潛水是另一個脈絡」→ 🟠
  - 「任何水下版本致命」→ 拆成「黑暈機制為生理鏈 🔵」+「在無監督的游泳訓練脈絡下此風險為禁忌 🟠」，並收斂「任何」這個全稱
- 查法：請 Claude 逐字段檢查 🔵 是否真的「不靠文獻」就能推導；對每個 🔵 自問「如果只給我物理與解剖課本，我能推出這句嗎？」。
- 信心：高

### 4｜grading.axes_zh[0]
- 原文：「感知線（在水裡）：按 **L0–L2** 分級。L0 水中連續吐氣 → L1 游進中持續吐氣 → L2 兩側換氣。」
- 類型：7
- 問題：把「兩側換氣」設為感知線終點，隱含所有學員最終都應該兩側換氣。許多成人初學、masters、休閒學員的合理終點是 L1（游進中能持續吐氣），兩側換氣對他們是不必要的競技延伸目標。grading.caveat_zh 自己也承認這幾族文獻缺，卻在 axes 把 L2 設為通則終點。
- 建議：補一句「L2 兩側換氣為競技／長距離泳者的延伸目標；成人初學、masters、休閒學員的感知線合理終點可停在 L1」。
- 查法：grep `L2` 與 `兩側` 共現；對照 framework.yaml 內對「成人初學」「masters」「para」三族是否在 axes 層級有獨立設計。
- 信心：中

### 5｜overview.links.development_stages 與 grading.links.development_stages
- 原文：兩處都列 `development_stages: [l2t, t2t, t2c, t2w]`
- 類型：7
- 問題：四個 development stage 全是加拿大 LTAD 的「train」軸（learn-to-train → train-to-win），未列 active start（幼兒）、active for life（成人休閒）等。grading.caveat_zh 點名成人初學／masters／para 文獻缺，但三條線的設計（特別是 L2 兩側換氣、% MIP 漸進、共振呼吸長期化、迷走張力）明顯以競技培育軸為預設讀者。讓成人休閒初學讀者打開這章，會拿到一份以競技賽前焦慮為例的框架。

- 查法：grep `development_stages` 在 framework.yaml 第 1 段全部出現；對照專案內 LTAD 與 r2w / masters / para 對應的 stage 定義是否存在；請 Claude 確認三條線描述中有無任何針對非競技族群的設計。
- 信心：中

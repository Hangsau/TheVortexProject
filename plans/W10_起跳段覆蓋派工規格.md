## 這一層在做什麼（寫任何一個字之前先讀完）

動作圖譜是**列舉式**的：列出「這個相位牽涉到什麼關節動作、可能有哪些狀況」，
**不判定誰主導、不判定某個泳者被什麼限制、不規定要練到幾度、不裁決哪一種教法較好**。

起跳段是全庫**最容易寫成處方**的一段，因為素材裡充滿「最優值」與「哪種較快」。
因此以下句型一律不得出現，出現即退件：

- 「最優膝角度是 X」「臀部應高於肩 X」「入水深度應為 X」——**這是門檻**
- 「後重心優於前重心」「Kick Start 比 Track Start 快」——**這是裁決哪種較好**
- 「主要由 X 肌群驅動」「X 是起跳的主動肌」——沒有相位化肌電振幅資料
- 「先練 X 再練 Y」「找出限制你的那塊肌肉」——**這是處方**
- 「後腿踢貢獻最多能量」「入水距離是最強預測因子」——**推進與成績歸屬本輪一律不寫**。
  庫裡確實有這類記錄（`starts-turns.tech.12`、`tech.43`），但它們的證據是游泳
  運動學與成績相關，不是本輪的解剖命名工作；把它們搬進 movement 層等於跨層借證。

### 數字紀律（W019 會擋）

`public` 底下的敘述文字裡**不得出現任何數值、角度、百分比、公尺或公分**。
素材裡的膝角度區間、髖屈角、肩複合體角度、觸牆深度、入水深度**一律不寫進敘述**，
改寫成定性說法（「屈曲量在一段區間內、且該區間隨個人肌肉特性移動」
「上舉接近可用範圍的上端」）。
本輪**不使用** `measurement_conditions` 欄位——本輪四筆的內容是**關節命名與可用範圍**，
不是起跳的量測結果，硬塞六欄量測條件就是造假。若某句話非要帶數字才成立，
那句話就不屬於本輪，直接不寫。

### 兩欄鐵律（本輪的核心，BK-30 錨點）

**池畔可見方向**與**解剖學動作**是兩個欄位，不是同一件事。
`poolside_direction` 寫池畔看到什麼、教練會說出口的那句話；
`action_ids` 與敘述寫解剖學怎麼命名。

**兩欄不一致而未在敘述中標明，一律退件。**
而且不一致處**不得只寫解剖名而不寫池畔說法**——讀者要能從自己聽過的那句話
找到這條記錄。正確寫法是「池畔會說 A，解剖上這是 B，兩者不一致的原因是 C」。

本輪有 **三種**兩欄不一致，每一種的處理方式不同：

| 型 | 樣態 | 處理 |
|---|---|---|
| **型甲：方向反轉** | 池畔看到的方向與解剖命名相反 | **必寫**，說明反轉原因（軀幹朝向） |
| **型乙：可見現象不是關節動作** | 池畔那句話對到的是空間軌跡、重心策略或關節間時序 | **標明它不是關節動作**，說明它實際對到什麼 |
| **型丙：可見現象是姿勢不是動作** | 池畔講的是起始位置，不是一個會發生的動作 | 寫成「此相位的位置有哪幾種並存設置」，不寫成動作 |

### 頸椎的寫法（強制，不得例外）

庫內**沒有** `neck.extension` / `neck.flexion`，**也不需要有**。
`movement.action.trunk.extension` 與 `movement.action.trunk.flexion` 的
`joint_region` 就是 `spine-neck`，其定義本身要求「不標節段就無法驗證」。

因此本輪凡是「抬頭」「頭中立」「下巴貼胸」，一律：
1. `action_ids` 寫 `movement.action.trunk.extension` 或 `movement.action.trunk.flexion`；
2. **敘述中明寫「此處指的是頸椎節段」**。

**不得新增 `neck.*`，不得因為名字叫 trunk 就改寫成「軀幹」而不提頸椎。**

`name_zh`：起跳零位的並存設置——這裡是姿勢不是動作

**這一筆的性質先講清楚**：零位是一個**被保持的位置**，不是一個會發生的動作。
所以 `action_ids` 列的是「這些關節在零位處於什麼位置」，不是「零位期間做了這些動作」。
這句要正面寫進 `description` 的第一段，否則整筆會被讀成一串動作指令。

`description` 必須依序寫齊五件事：

1. **屈膝成立，但屈曲量沒有跨選手的通用最優值**。素材明說最優屈曲量與個人肌肉
   特性高度相關，不同人的最佳點落在不同位置。因此本筆記錄的是「此相位膝處於
   屈曲位」，**不記錄任何角度區間**，也不寫「越深越好」或「越淺越好」。

2. **「臀部高於肩」在解剖上是髖屈曲加軀幹前傾**。方向命名成立。但要寫明：
   池畔講的「臀高於肩」是**兩個身體部位的相對高度**，是空間關係；它由髖屈曲量、
   軀幹前傾角與下肢屈曲量共同決定，**不能由高度差反推髖屈曲了多少**。

3. **頭位有兩種並存教法，本層不選邊（型丙）**。素材記錄了兩派：一派主張頭保持
   中立、一派主張動態抬頭，兩派都有實務代表。在解剖命名上這兩派差的是**頸椎節段
   的起始位置**（介於 `trunk.flexion` 與 `trunk.extension` 之間，**此處指頸椎節段**），
   **差的是起始位置不是動作**。要寫成「此相位頸椎的設置有兩種並存教法」，
   **不得寫成「應保持中立」或「應抬頭」**。

4. **「手抓台板往上拉」是肩複合體伸展（型甲的輕度版本）**。池畔看到的是「拉」，
   方向感覺是往上、往前；解剖上，手固定在台板、身體相對手往前移，肱骨相對軀幹
   往後方去，命名是**肩複合體伸展**。這一列要寫出來，因為「拉」這個字很容易被
   對成屈曲。肘的部分：素材明說直臂與屈肘兩種抓握的效率接近，因此 `action_ids`
   **兩個都列**，敘述寫「肘可處於屈曲或接近伸展位，兩者並存」。

5. **「身體稍微往後坐」不是關節動作（型乙）**。前傾與後仰兩種設置差的是**整體

## 這一層在做什麼（寫任何一個字之前先讀完）

動作圖譜是**列舉式**的：列出「這個相位牽涉到什麼關節動作、可能有哪些狀況」，
**不判定誰主導、不判定某個泳者被什麼限制、不規定要練到幾度**。

因此以下句型一律不得出現，出現即退件：

- 「主要由 X 肌群驅動」「X 是主動肌」「X 出力最多」——沒有相位化肌電資料
- 「找出限制你的那塊肌肉」「先練 X 再練 Y」——這是處方
- 「應達到 N 度」「至少要 N 度才能做出蛙腿」——這是門檻
- 「研究顯示」——本輪的來源是解剖教科書，只能寫「解剖來源指出」

`evidence_profile` 全部是 `anatomy`，意思是：**這些來源只支持關節命名與一般
解剖可用能力，不支持任何蛙式專項的運動學、時序或推進宣稱**。所有 `muscle_roles`
的 `role` 敘述都必須自己聲明這個邊界（照本檔給的樣板句寫）。

### 數字紀律（W019 會擋）

`public.description` 等敘述文字裡**不得出現 `°`、`%`、`s`、`r=`**。
教科書的角度值（40–45°、12.5°、120° 之類）**一律不寫進敘述**，改寫成定性
說法（「可用範圍明顯小於…」「上限受韌帶與內收肌群限制」）。
本輪**不使用** `measurement_conditions` 欄位——因為這些數值是教科書的一般
解剖範圍，不是蛙式的量測結果，硬塞六欄量測條件就是造假。

### 兩欄鐵律（BK-30 已定案，本輪沿用）

**池畔可見方向**與**解剖學動作**是兩個欄位，不是同一件事。
`poolside_direction` 寫池畔看到什麼，`action_ids` 與敘述寫解剖學怎麼命名。
蛙式是俯臥（`body_position: prone`），不像仰式會反轉矢狀面命名，但
「大腿分開」「腳跟靠近臀部」「腳尖朝外」這三個可見現象**都不能直接反推
關節動作**——這正是本輪四個相位裡最重要的內容（見下面 BR-23、BR-28）。

## 前置裁決：蛙式的相位歸屬（執行者不得更動）

蛙式登錄的分期是 `descriptive`。裁決檔的相位前綴與登錄相位鍵對應如下：

| 登錄相位鍵 | 裁決檔前綴 | 可用的裁決條目 |
|---|---|---|
| `arm-outsweep` 外划 | 「外掃／下掃期」 | BR-04、BR-05、BR-07、BR-08 |
| `arm-catch` 捕水 | 「抓水期」 | BR-09、BR-10、BR-11 |
| `leg-recovery` 收腿 | 「收腿期」 | BR-21、BR-22、BR-23、BR-25、BR-26＋BR-24（B 類 ROM） |
| `foot-flip` 翻腳期 | 「翻腳／外轉期」 | BR-27、BR-28 |

**負面清單（本輪絕對不得產出的內容）**：

1. **不得寫「高肘」的任何實質內容**。BR-09、BR-15 都判部分支持，理由是
   「高肘」是游泳專屬技術構念，同時包含肘相對手掌的高度、前臂朝向與推進
   假設，超出解剖教科書可裁決範圍。可用的只有「肘屈曲增加」六個字。
   敘述裡可以說「教材另有『高肘』一詞，該詞涉及推進假設，不在本層裁決範圍」，
   但不得描述高肘的做法、好處或判準。
2. **不得宣稱髖外旋在收腿期不存在**。BR-23 判「修正」修的是**證據**不是
   結論：「大腿分開」是髖外展、「腳跟往臀部拉」是膝屈曲，兩個都不是髖旋轉
   的證據；但髖外旋本身**未被否證**，解剖上完全可能。敘述必須寫成
   「這兩個可見現象不能當髖旋轉的判斷依據」，不是「收腿期沒有髖外旋」。
3. **不得把外翻歸給踝關節**。BR-26、BR-28 是本批唯一兩本教科書一致硬裁決的
   點：距小腿關節只有一個主要自由度（背屈／蹠屈），外翻發生在距下關節與
   橫跗關節。所有提到外翻的地方都要寫成「距下關節／橫跗關節」。
4. **不得把「腳尖朝外」歸給任何單一關節**。它是四個貢獻源的向量和（髖外旋、
   膝軸向旋轉、距下旋前、橫跗關節），見 BR-28 與既有記錄 `breast.tech.36`。
5. **不得寫蛙式蹬夾（`leg-insweep`）、滑行（`glide`）、內划（`arm-insweep`）、
   回臂（`arm-recovery`）的新內容**——這四個相位已有 demand，本輪不動。
6. **不得寫任何傷害宣稱**（膝外翻應力、肩前脫位等）。那些是 C 類，在
   `plans/關節主張裁決_C類傷害宣稱.md` 另行處理，不進本輪。

### A1 `movement.action.shoulder-complex.external-rotation`

| 欄位 | 值 |
|---|---|
| `name` | 肩外旋 |
| `aliases` | `[肩關節外旋, 肱骨外旋, shoulder external rotation]` |
| `joint_region` | `shoulder-arm` |
| `plane` | `[transverse]` |
| `axis` | `[肱骨縱軸]` |
| `claim_status` | `supported` |
| `action_status` | `ready` |
| `source_ids` | `[src.neumann-2017]` |

`definition` 要寫：從解剖位置起算，肱骨繞其縱軸向外側轉動的水平面動作。
`observable_boundaries` 要寫兩件事：①**可用範圍隨起始上舉角度改變**——由內收位
起算與由外展位起算不是同一個可用範圍（定性寫，不給數字）；②解剖來源指出
**肩在往外展方向上舉的過程中，肱骨會自然伴隨外旋**，讓肱骨大結節從肩峰後方
通過、避開肩峰下空間，所以外旋常常不是獨立選擇的動作而是上舉的必然伴隨成分。
第②點是 BR-05 的核心，必須寫進去。

`definition` 的關鍵：這個動作的**起始參考位置是外展約直角的位置**，肱骨繞垂直軸

### A4 `movement.action.hip.external-rotation`

| 欄位 | 值 |
|---|---|
| `name` | 髖外旋 |
| `aliases` | `[髖關節外旋, 股骨外旋, hip external rotation]` |
| `joint_region` | `hip-knee` |
| `plane` | `[transverse]` |
| `axis` | `[股骨頭中心到膝關節中心的縱軸]` |
| `claim_status` | `supported` |
| `action_status` | `ready` |
| `source_ids` | `[src.neumann-2017]` |

**這一筆的 `observable_boundaries` 是本輪最重要的一段**，必須寫齊三點：
1. 髖旋轉的縱軸是股骨頭中心到膝關節中心的連線；由於股骨頸傾斜角與股骨幹前弓，
   **這條軸大部分落在股骨本體之外**，因此沒有任何體表可見的標記直接對應它。
2. 小腿與腳跟的位置**另外**受膝關節軸向旋轉影響，而膝在部分屈曲時軸向旋轉
   最自由。因此同一個腳跟位置可以由髖旋轉、膝旋轉或兩者的任意組合達成。
3. 可用的判定方式是直接量測股骨繞其縱軸的旋轉（大腿標記點或影像），或以
   標準體位徒手測角；**不得以腳跟、小腿或大腿分開的程度反推髖旋轉**。

`definition`：脛骨相對股骨繞縱軸的旋轉，是膝關節在矢狀面屈伸之外的第二個

| 欄位 | 值 |
|---|---|
| `name` | 踝背屈 |
| `aliases` | `[背屈, 踝關節背屈, 勾腳, ankle dorsiflexion]` |
| `joint_region` | `ankle-foot` |
| `plane` | `[sagittal]` |

| `claim_status` | `supported` |
| `action_status` | `ready` |

`definition`：足相對小腿在矢狀面朝小腿前側靠近的動作，發生在距小腿關節，

`observable_boundaries`：①**背屈的關節歸屬明確**——距小腿關節只有一個主要

膝與踝的雙關節肌在屈膝時被縮短，所以「屈膝時的背屈」與「伸膝時的背屈」不是
同一個條件下的量，比較前要指明膝角度。

### A8 `movement.action.ankle-foot.pronation`

| 欄位 | 值 |
|---|---|
| `name` | 距下／橫跗關節旋前 |
| `aliases` | `[旋前, 足旋前, subtalar pronation, foot pronation]` |
| `joint_region` | `ankle-foot` |
| `plane` | `[oblique]` |
| `axis` | `[距下關節斜軸, 橫跗關節縱軸與斜軸]` |
| `claim_status` | `supported` |
| `action_status` | `ready` |
| `source_ids` | `[src.neumann-2017, src.nordin-frankel-2012]` |

**這一筆是本輪的命名修正核心**，`definition` 與 `observable_boundaries` 要寫齊：
1. 旋前是**單軸三平面**運動，主成分為外翻＋外展，並含背屈成分。
2. 兩本解剖來源一致：**外翻不發生在距小腿關節**。距小腿關節只有背屈／蹠屈
   一個主要自由度；外翻是繞前後軸的額狀面動作，發生在**距下關節**與
   **橫跗關節**。把外翻寫成「踝關節外翻」是單一關節誤稱。
3. 三個成分**不可分離**——其中任一成分存在，就代表另兩個成分也正在發生。
   因此在同一相位裡把「背屈」與「外翻」寫成兩個獨立動作，可能其實是同一個
   旋前動作的兩個成分被拆成兩格。
4. 主動外翻的可用範圍**很小**（定性寫，不給數字），且外踝下伸與較厚的三角
   韌帶會自然限制它。所以它**不足以**單獨造成腳掌明顯朝向外側——腳掌方位的
   主要來源在更近端的關節（見 A4、A6）。

```yaml
    body_position: prone
```

### D1 外划

```yaml
  - id: movement.demand.breast.arm-outsweep.elevation-plane-with-obligatory-external-rotation
    phase: arm-outsweep
    poolside_direction: 由池畔觀察，雙手自頭前併攏位置向兩側分開（教學語稱「外划」）
    derived_from_ids:
      - breast.tech.3
      - breast.tech.24
    action_ids:
      - movement.action.shoulder-complex.elevation
      - movement.action.shoulder-complex.external-rotation
      - movement.action.elbow.flexion
      - movement.action.wrist-hand.flexion
    claim_status: partially-supported
```

`muscle_roles`：`movement.muscle.scapular-upward-rotators`、
`movement.muscle.rotator-cuff`、`movement.muscle.elbow-flexors`、
`movement.muscle.wrist-flexors`。

`name_zh`：蛙式外划的上舉平面、必然外旋與肘腕輕度屈曲

`description` 必須說清楚兩件事：
1. **為什麼不直接叫「肩外展」**（BR-04）：外划的起始位是雙手在頭前接近最大
   上舉，從那個位置把手向外分開，在解剖體系裡是**上舉平面由矢狀面移向肩胛
   平面或額狀面**，不是從手臂貼體側起算的額狀面外展；如果外划進行到上舉角度
   降到接近直角，那個平面內的向外移動又要改稱水平外展。**所以「外展」這個名字
   要能用，必須先講清楚起始上舉角度與上舉平面**——這正是 `claim_status` 只給
   `partially-supported` 的原因。方向描述（肱骨向外側移動）本身成立。
2. **外旋不是可選項**（BR-05）：往外展方向上舉時肱骨會自然伴隨外旋，讓大結節
   從肩峰後方通過。所以外划期標出外旋不是多餘的細節，是上舉本身的必然成分。

`limitation_context`：上舉平面、上舉角度、外旋與肘腕屈曲各有獨立的可用範圍與
控制條件；從池畔看到的「手向外分開」是這些的合成，**不能指出限制位於哪一個
關節或哪一個成分**。

`safety_note`：外划時若出現肩部疼痛、卡住、麻木、明顯無力或不穩應停止，
不要為了把手分得更開而勉強增加上舉角度或改變上舉平面。

### D2 捕水

```yaml
  - id: movement.demand.breast.arm-catch.horizontal-adduction-with-rotation-reversal
    phase: arm-catch
    poolside_direction: 由池畔觀察，雙手停止向外分開、開始朝身體中線收攏（教學語稱「捕水」）
    derived_from_ids:
      - breast.tech.4
    action_ids:
      - movement.action.shoulder-complex.horizontal-adduction
      - movement.action.shoulder-complex.internal-rotation
      - movement.action.elbow.flexion
    claim_status: partially-supported
```

`muscle_roles`：`movement.muscle.shoulder-internal-rotator-extensors`、
`movement.muscle.elbow-flexors`。

`name_zh`：蛙式捕水的水平內收命名與旋轉方向反轉

`description` 三件事：
1. **方向反轉成立**（BR-10 可用的部分）：肱骨停止遠離中線、開始朝中線移動，
   這個轉折本身描述得沒有問題。
2. **但名稱基準要換**：捕水時手臂位於體前、上舉接近直角，此時肱骨朝中線移動
   的正確名稱是**水平內收**，不是額狀面的內收。用錯基準的後果是後續的活動度
   比較與陸上輔助動作會對到不同平面的動作。
3. **旋轉方向反轉是乾淨的**（BR-11）：外划期的外旋在捕水期轉為內旋，這是繞
   肱骨縱軸的軸向旋轉方向改變，直接對應解剖定義，**而且它不依賴任何從手掌
   朝向做的反推**——手掌在空間中朝哪裡與前臂、肱骨的關節位置是不同欄位。
4. 肘屈曲增加成立；教材另有「高肘」一詞，該詞涉及肘相對手掌的高度、前臂朝向
   與推進假設，**不在本層的裁決範圍**，本筆不描述其做法或判準。

`limitation_context`：水平內收、軸向內旋與肘屈曲各自獨立；池畔看到的「手收攏」
是三者的合成，不能指出限制在哪一項，也不能由外觀指定任何肌群的收縮方式。

`safety_note`：捕水時若出現肩前側疼痛、卡住、麻木、明顯無力或不穩應停止，
不要為了讓手更快收攏而加大內旋幅度。

### D3 收腿

```yaml
  - id: movement.demand.breast.leg-recovery.hip-flexion-abduction-with-knee-flexion
    phase: leg-recovery
    poolside_direction: 由池畔觀察，雙腳跟朝臀部方向收近、雙膝與大腿同時分開（教學語稱「收腿」）
    derived_from_ids:

```

`muscle_roles`：`movement.muscle.hip-flexors`、`movement.muscle.hip-abductors`、
`movement.muscle.hip-external-rotators`、`movement.muscle.knee-flexors`、
`movement.muscle.ankle-dorsiflexors`。

`name_zh`：蛙式收腿的髖屈曲外展、膝屈曲與踝背屈，以及可見現象的歸屬

`description` 必須依序寫這四段：
1. **髖屈曲**（BR-21）：大腿朝腹側移動即命名為髖屈曲。要註明這一欄記的是
   **動作方向**不是關節位置——只要股骨朝前旋轉就稱屈曲，不論是往中立位靠近
   還是超過中立位，所以收腿起始時髖可能仍在伸展角度卻已經在做屈曲。
2. **髖外展**（BR-22）：**「大腿分開」的正確歸屬欄位是髖外展**。
3. **「腳跟往臀部拉」是膝屈曲，不是髖旋轉**（BR-23，本筆最重要的一段）：
   腳跟接近臀部就是膝屈曲角度增加的直接定義。要接著寫髖旋轉為什麼**不能**
   從遠端反推——旋轉軸大部分落在股骨本體之外、沒有體表標記；小腿與腳跟位置
   又另外受膝軸向旋轉影響，而膝在部分屈曲時軸向旋轉最自由，收腿正是深屈膝。
   最後必須明寫：**這不代表收腿期沒有髖外旋**，髖外旋在解剖上完全可能，
   只是「大腿分開」與「腳跟位置」這兩個可見現象都不是它的證據。
4. **踝背屈的關節歸屬正確**（BR-25）：背屈確實發生在距小腿關節。但要註明
   收腿期的背屈是在**深屈膝**條件下進行的，與伸膝時的背屈不是同一個條件，
   兩者不能互相代表。

`limitation_context`：髖屈曲、髖外展、髖外旋、膝屈曲與踝背屈各有獨立的可用
範圍與控制條件，其中髖外展的限制源偏向恥股韌帶與內收肌群的被動張力，髖外旋
的可用量隨髖屈曲角度改變。**從池畔看到的收腿寬度與腳跟位置是這些的合成，
不能指出限制位於哪一個關節。**

`safety_note`：收腿時若出現髖部、鼠蹊、膝內側、腰背或踝部疼痛、卡住、麻木、
明顯無力或不穩應停止，不要為了把腳跟拉得更近或把膝分得更開而強壓。

`movement.muscle.foot-evertors`、`movement.muscle.hip-external-rotators`、
`movement.muscle.knee-flexors`。

`name_zh`：蛙式翻腳的「腳尖朝外」是多關節合成，外翻不發生在距小腿關節

`description` 必須依序寫這三段：
1. **關節歸屬更正**（BR-26／BR-28）：兩本解剖來源一致——距小腿關節只有背屈／
   蹠屈一個主要自由度，外翻是額狀面動作，發生在距下關節與橫跗關節。
   所以「踝關節外翻」是誤稱，正確寫法是**距下關節／橫跗關節旋前**。
2. **「腳尖朝外」是四個貢獻源的向量和**，四者可同時發生，池畔或水下攝影看到的
   是合成結果，不能整個歸給任一單一關節。四個貢獻源與各自的性質：
   - **髖外旋**：股骨繞縱軸外轉帶動整條下肢，是幅度最大的來源，但無法從
     遠端位置反推（見 D3）。
   - **膝軸向旋轉**：脛骨相對股骨外旋，只在膝屈曲時存在且部分屈曲時最自由，
     而翻腳期膝正處於深屈曲。
   - **距下關節旋前**：其外展成分使前足相對小腿轉向外側，但可用幅度很小。
   - **橫跗關節**：足部最靈活的關節，有兩條旋轉軸。
3. **教科書能硬支持的一件正面事實**：旋前是單軸三平面運動，三個成分的組合
   不變——任一成分存在就代表另兩個也在發生。因此「足部外翻會伴隨腳尖外轉」
   這個定性關聯是**成立**的；不成立的是把幅度、關節歸屬與因果整個壓在「踝」
   這一格。也因此，同一相位裡的「持續背屈」與「外翻」有可能是同一個旋前動作
   的兩個成分，不必然是兩個獨立動作。

`limitation_context`：四個貢獻源各有獨立的可用範圍，且髖外旋的可用量隨髖屈曲
角度改變、膝軸向旋轉只在屈膝時存在。**看到腳尖朝外的角度不足，不能指出限制
位於髖、膝、距下或橫跗的哪一處**；要區分必須逐關節分別量測。

`safety_note`：翻腳時若出現膝內側、踝外側、足部或髖部疼痛、卡住、麻木、明顯
無力或不穩應停止，不要靠外力扳轉腳掌來增加朝外的角度。

`diagnostic.assessment_note`：評估時須把池畔可見的「腳尖朝外」與四個關節各自
的旋轉分開逐項記錄，不得以合成外觀指定任一關節的貢獻。現有解剖來源只支持
關節命名與一般可用能力，沒有蛙式專項運動學、相位化肌電或推進力量測，
故 `action_status` 維持 `provisional`。

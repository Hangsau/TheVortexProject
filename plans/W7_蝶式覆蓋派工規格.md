## 這一層在做什麼（寫任何一個字之前先讀完）

動作圖譜是**列舉式**的：列出「這個相位牽涉到什麼關節動作、可能有哪些狀況」，
**不判定誰主導、不判定某個泳者被什麼限制、不規定要練到幾度**。

因此以下句型一律不得出現，出現即退件：

- 「主要由 X 肌群驅動」「X 是主動肌」「X 出力最多」——沒有相位化肌電振幅資料
- 「找出限制你的那塊肌肉」「先練 X 再練 Y」——這是處方
- 「應達到 N 度」「至少要 N 度才能完成推水」——這是門檻
- 「內划是主推進相」「外划有推進力」——**推進歸屬本輪一律不寫**。
  庫裡確實有這類記錄（`fly.tech.12`、`fly.tech.13`），但它們的證據是游泳
  運動學文獻，不是本輪的解剖來源；把它們搬進 movement 層等於跨層借證。

### 數字紀律（W019 會擋）

`public.description` 等敘述文字裡**不得出現 `°`、`%`、`s`、`r=`**。
教科書的角度值（一百二十度、六十五度、七十五到八十五度之類）與
`fly.tech.12` 的加速度值**一律不寫進敘述**，改寫成定性說法
（「可用範圍在解剖上餘裕充足」「主動可達的後方範圍有限」）。
本輪**不使用** `measurement_conditions` 欄位——這些數值是教科書的一般解剖範圍，
不是蝶式的量測結果，硬塞六欄量測條件就是造假。

### 兩欄鐵律（BK-30 已定案，本輪沿用）

**池畔可見方向**與**解剖學動作**是兩個欄位，不是同一件事。
`poolside_direction` 寫池畔看到什麼，`action_ids` 與敘述寫解剖學怎麼命名。
蝶式是俯臥（`body_position: prone`），空間「向前」與解剖位的前方同向，
**不發生仰式那種矢狀面命名反轉**（BK-30／BK-33 錨點）。但下列三個可見現象
**都不能直接反推關節動作**，這是本輪的核心內容：

1. **「手向外分開」不等於額狀面外展**——起始上舉角度決定該用哪個名稱（D2）。
2. **「掌心朝向」不能反推肱骨旋轉**——掌心的空間朝向是肱骨軸向旋轉、前臂旋前
   旋後、腕關節位置三者的合成（D1、D6）。
3. **「拇指側先出水」不是關節動作**——它是整條上肢旋轉的函數，不是可命名的
   關節動作（D6）。

### A1 `movement.action.shoulder-complex.adduction`

| 欄位 | 值 |
|---|---|
| `name` | 肩內收 |
| `aliases` | `[肩關節內收, 肱骨內收, shoulder adduction]` |
| `joint_region` | `shoulder-arm` |
| `plane` | `[frontal]` |
| `axis` | `[肩外展內收的前後軸]` |

`definition`：肱骨在接近額狀面內朝身體中線方向的轉動，繞一條接近前後方向的軸，
以解剖位置為零度中立參考。

`observable_boundaries` 必須寫清楚**它與水平內收的分工**（這是本筆存在的唯一理由）：
額狀面內收與水平內收是**兩個不同基準的名稱**，不是同義詞，也不是彼此的粗細粒度。
水平內收的起始參考位置是外展接近直角、肱骨繞垂直軸向前移動；額狀面內收則是
以解剖位置為零度、肱骨在接近額狀面內朝中線移動。**一個實際發生在體前偏下的
朝中線移動，通常同時含有這兩個成分**，兩者可以並存且不互相取代——所以正確
做法是兩個都列，而不是挑一個代表。用單一名稱承載雙軸動作，會讓後續的活動度
比較與陸上輔助動作對到錯的平面。

`general_anatomical_capacity`：可用範圍受起始上舉角度、軀幹阻擋與軟組織張力
共同影響；肱骨越過身體中線的可能性取決於同時發生的屈伸與旋轉成分。
本條不以單一角度作能力門檻。

`diagnostic.assessment_note`：判定內收成分時必須先指明是相對哪個基準
（解剖位置零度 vs 外展直角起算），否則同一個詞在兩個基準下描述的不是同一件事。

### A2 `movement.action.shoulder-complex.scapular-retraction`

| 欄位 | 值 |
|---|---|
| `name` | 肩胛後縮 |
| `aliases` | `[肩胛骨後縮, 肩胛內收, scapular retraction]` |
| `joint_region` | `shoulder-arm` |
| `plane` | `[frontal]` |
| `axis` | `[肩胛骨沿胸廓表面的內外側平移]` |

`definition`：肩胛骨沿胸廓表面朝脊椎方向移動，是肩胛胸廓關節的動作，
方向與前伸相反。它常出現在「把物體拉向身體」的動作情境。

`observable_boundaries` 必須寫齊兩點：
1. **肩胛胸廓關節有三組互相獨立的動作軸**——上提／下壓、前伸／後縮、
   上迴旋／下迴旋。三組可以同時發生，**只描述其中一軸不代表另外兩軸處於中立**。
   一份只寫「後縮」的紀錄，正確讀法是「後縮這一軸被記了」，不是「另兩軸沒動」。
2. **肩胛骨是肱骨的活動平台，不是獨立於肱骨的動作**——肩胛的位置決定關節盂
   朝向，因此同一個肱骨動作在不同肩胛位置下對應的關節內相對位置並不相同。
   描述肩胛動作時要指明當時的肱骨上舉狀態。

`general_anatomical_capacity`：可用範圍受胸廓形狀、前伸方向軟組織張力與
當時的肱骨上舉角度共同限制。本條不以單一角度作能力門檻。

`diagnostic.assessment_note`：由體表看到的「肩胛往脊椎靠」可能同時含有後縮與
下迴旋兩種成分；要分開判定必須各軸分別量測，不得由單一外觀指定其中一軸。

### D1 入水 — **本輪最重要的一筆，請完整讀完再寫**

```yaml
  - id: movement.demand.fly.entry.elevation-plane-and-contested-rotation-direction
    phase: entry
    poolside_direction: 由池畔觀察，雙手同步在頭前入水並向前延伸，兩手入水點通常略寬於肩線（教學語稱「入水」）
    derived_from_ids:
      - fly.tech.13
      - fly.tech.37
      - fly.tech.38
    action_ids:
      - movement.action.shoulder-complex.elevation
      - movement.action.shoulder-complex.external-rotation
      - movement.action.shoulder-complex.internal-rotation
      - movement.action.wrist-hand.flexion
    claim_status: disputed
```

`muscle_roles`：`movement.muscle.scapular-upward-rotators`、
`movement.muscle.rotator-cuff`、`movement.muscle.wrist-flexors`。

`name_zh`：蝶式入水的上舉平面、旋轉基準，與旋轉方向的來源分歧

**為什麼 `action_ids` 同時列了外旋與內旋**：這正是本筆要記錄的事。圖譜是列舉式的
——**把可能的狀況都標示出來**，而不是替讀者選一個。兩個方向各有來源，本層不裁定
哪個對。**不得刪掉其中任何一個，也不得把其中一個寫成「錯誤說法」。**

`description` 必須依序寫齊四件事：

1. **「手臂前伸過頭」不是單一關節事件**（BF-01）。盂肱關節本身提供的屈曲範圍
   有限，接近完全過頭的上舉必須加上肩胛胸廓的上迴旋。所以正確的承載名稱是
   **肩複合體上舉**，並註明兩處貢獻，而不是把「伸最遠」整個掛在肩關節上。

2. **不要寫成「屈曲加一點外展」**（BF-02）。原始教材用兩個動作名硬湊出一個
   平面資訊。解剖體系處理上舉的方式是用**上舉平面**來命名同一個上舉動作：
   蝶式雙手入水點通常在肩線外側略寬，正確表述是「上舉平面介於矢狀面與
   肩胛平面之間」，不是「屈曲＋些微外展」。兩種術語系統混用就是錯的。
   方向描述（肱骨略偏離中線）本身成立。

3. **旋轉必須先講基準，否則同一個詞在兩個基準下意義相反**（BF-03，本筆核心）。
   「些微內旋」是相對於什麼零點？(a) 解剖位置零度，還是 (b) 該上舉角度下
   **依解剖原理應有的外旋量**？兩者相差很大。解剖來源指出：肩往外展方向上舉時，
   肱骨會自然伴隨外旋，讓肱骨大結節從肩峰後方通過、避開肩峰下空間——
   **在接近最大上舉時，外旋是義務性的，不是可選的修飾動作**。因此若以 (b) 為
   基準，「內旋傾向」的意思其實是「比應有的外旋少」，那是完全不同的一件事。
   **旋轉欄位不標基準就無法判讀，這是本筆列為 `disputed` 的第一個理由。**

4. **兩個來源對入水旋轉方向的說法不一致，本層不選邊**（`fly.tech.38`）。
   一邊是教材敘述的「入水些微內旋傾向」；另一邊是本專案文獻集中唯一一份
   蝶式肩的一手研究（十二條肌肉肌電圖加電影分析），它描述的入水肱骨是
   **外展併外旋**，同時肩胛骨後縮並上迴旋為肱骨備好關節盂平台。這與上舉平面
   的推論同向：蝶式雙手同步、沒有軀幹縱軸滾轉，上舉平面推論上比自由式更靠近
   額狀面，而額狀面上舉與義務性外旋的耦合最強。
   **敘述要把兩個說法都寫出來並標明各自的依據性質（教材敘述 vs 一手量測），
   然後說明本層不裁定。** 這一段還要補一句方法紀律：**掌心在空間中朝哪裡不能
   反推肱骨旋轉**——掌心朝向是肱骨軸向旋轉、前臂旋前旋後、腕關節位置三者的
   合成，要判定肱骨旋轉需要肱骨本身的參考標記或影像。

   ⚠ **這一段的三條禁令**：①**不得寫「蝶式入水是夾擠位置」**，那句話追不到
   一手量測支持；②**也不得反過來寫成安全保證**（例如「所以入水不會夾擠」）
   ——本層裁定的是「方向說法不一致」，不是「安全」；③該一手研究對入水肱骨
   另用了「伸展」一詞，與手臂前伸過頭的外觀直覺不符，可能與其分期定義或量測
   參考軸有關，**目前只有摘要未取全文，這一項完全不寫**。

5. 腕輕度屈曲成立（BF-04），落在正常屈曲範圍內，無附掛成分。

`limitation_context`：上舉平面、上舉角度、旋轉基準、旋轉方向與腕屈曲各有獨立的
可用範圍與判讀條件；從池畔看到的「雙手入水前伸」是這些的合成，**不能指出限制
位於哪一個關節或哪一個成分**，也不能由入水點寬窄反推任何旋轉方向。

`safety_note`：入水與前伸時若出現肩部疼痛、卡住、麻木、明顯無力或不穩應停止，

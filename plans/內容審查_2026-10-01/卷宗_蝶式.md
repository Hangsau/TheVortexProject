## 題 37

**問題**：入水手型：fly.tech.15／fly.tech.21「拇指先 45° 切入」vs fly.err15「手腕中性、掌面平行水面接觸，不是用手指戳水」、fly.err2「平整入水」、fly.err4「小指朝上」回臂。

**原文**：
```
== fly.tech.15
  title: 蝶式划水與四式對比
  summary: 蝶式以拇指先 45° 切入入水，雙臂同步 S 形/橢圓路徑划水，水上低位弧線回臂；Insweep 峰值（4.2 m/s²）是四式最高量化推進峰值。
  certainty: 🔵
  text: 蝶式雙側對稱划水與自由式交替、仰式交替在驅動模式上根本不同；蛙式 Insweep 與蝶式同為雙臂向內，但蛙式後接收腿循環，蝶式後接空中恢復。
  practical_implication: 混合式（IM）選手在蝶式與蛙式間切換是訓練難點，兩式的驅動邏輯不可互相代入。
```
```
== fly.tech.21
  title: 入水停頓機制：水平動量轉換為垂直動量
  summary: 入水瞬間的受控停頓讓前向水平動量轉換為胸部下壓的垂直動量，直接助力第一踢腿加速；過快或過深入水反而讓動量在水的阻力中消散。
  certainty: 🔵
  text: 入水停頓是能量轉換機制，不是技術猶豫——動量在介質切換時的方向轉換需要受控的減速緩衝區；跳過此環節等於丟失一部分由 Recovery 帶來的動能輸入。
  practical_implication: 入水技術目標是「拇指先 45° 切入後受控停頓」，不是持續向前衝入。
```
```
== fly.err15
  title: 入水手指先入、手腕折下——破壞高肘設定造成 EVF 早期崩潰
  misconception: 部分教練教蝶式入水時「手指先入、手腕往下彎讓手指撥開水」， 立意是「乾淨入水減少阻力」。但執行端造成手腕過度屈曲， 入水後手腕鎖在彎曲位、無法接續做出高肘 EVF， 反而把整個拉水週期的最大推進相（Insweep）的設定鎖死。
  certainty: 🟠
  text: 蝶式入水後立刻要進入捕水→Insweep 的高肘狀態。 手腕折下造成兩個連鎖問題：① 手腕屈曲位置無法快速翻回高肘所需的「手腕中性」狀態； ② 入水瞬間的橫向力造成手肘略內收（自然反射），EVF 設定變得更困難。 菁英蝶式選手入水時手腕保持中性、手掌與前臂在同一平面， 入水後手腕、肘、肩線順勢進入 EVF 設定——這需要手腕從一開始就不折下。 「乾淨入水」的目標應該透過「手掌成扁平面、平行入水」達成，不是「手指先入」。
  cross_ref: EVF（早期垂直前臂）在蝶式的實現路徑、入水停頓機制
  correct_concept: 入水手腕保持中性（直），手掌平面與水面平行接觸—— 像把手放下接觸桌面，不是用手指戳水。 這樣入水後手腕、前臂、肘可直接接續做 EVF 高肘設定。
  perception_impact: 手腕折下的口令把感知焦點放在「手指有沒有先入」的入水形式， 錯失了「入水後手腕能否接續高肘」的功能性目標。 正確的感知是「入水後手腕仍有自由度做下一個動作」。
```
```
== fly.err2
  title: 蝶式雙手入水位置要靠近中線甚至額頭正前方
  misconception: 部分教練指示學員雙手入水位置靠近中線，甚至幾乎在額頭正前方入水，認為這樣能降低阻力 或保持身體對稱。
  certainty: 🔵
  text: 正確入水點應在肩線延伸前方（11點與1點鐘位置）。入水過窄會讓捕水角度不良，直接影響 EVF 的建立。 入水過窄還導致外划幅度過大（必須向外移動更多距離才能到達捕水位置），反而增加了外划的阻力代償。
  certainty: 🟠
  text: 手部入水應略寬於肩膀——想像把雙手放在時鐘的 11 點與 1 點位置。手部應平整入水，水花極少。
  cross_ref: 外划（Outsweep）功能重建、EVF（早期垂直前臂）在蝶式的實現路徑
  correct_concept: 入水點約肩線寬度、手臂接近完全伸展，指尖朝前斜下切入。過窄入水會讓抓水失去力矩支撐， 影響 EVF 品質。
  perception_impact: 入水過窄時，外划必須更費力，捕水感知建立被幹擾——學員感受到的是「外划的努力感」 而非「捕水位置到達感」。
```

## 題 38

**問題**：入水後：fly.tech.21／fly.tech.12「入水受控停頓、減速→靜止→爆發」vs fly.err16「入水後立刻 outsweep」。

**原文**：
```
== fly.tech.21
  title: 入水停頓機制：水平動量轉換為垂直動量
  summary: 入水瞬間的受控停頓讓前向水平動量轉換為胸部下壓的垂直動量，直接助力第一踢腿加速；過快或過深入水反而讓動量在水的阻力中消散。
  certainty: 🔵
  text: 入水停頓是能量轉換機制，不是技術猶豫——動量在介質切換時的方向轉換需要受控的減速緩衝區；跳過此環節等於丟失一部分由 Recovery 帶來的動能輸入。
  practical_implication: 入水技術目標是「拇指先 45° 切入後受控停頓」，不是持續向前衝入。
```
```
== fly.tech.12
  title: 外划（Outsweep）功能重建：定位準備而非主動推進
  summary: 外划有約 1.4 m/s² 的推進力（升力機制），但不允許被主動強調；其核心功能是讓手臂到達 EVF 起始位置的捕水準備動作。
  certainty: 🔵
  text: 主動外划干擾「減速→靜止→爆發」的節奏，壓縮 Insweep 的加速空間；理論最優幅度是「足以接收第一踢波動慣性、到達捕水位置所需的最小幅度」——過大或過小均為次優解。
  certainty: 🟢
  text: 疲勞狀態下外划的手部方向偏移使有效推進力進一步下降，支持最小幅度外划原則
  certainty: 🟡
  text: 外划階段存在升力推進，但貢獻可能被部分研究高估
  practical_implication: 外划技術目標應設為「最小必要幅度的捕水位置準備」，不以外划形狀作為技術目標。
  cross_ref: 2024–2025 外划幅度縮小趨勢已成為精英教學主流演進方向
```
```
== fly.err16
  title: 入水越深、起手越輕鬆
  misconception: 部分教練教「入水越深越好，這樣起手時水阻小、感覺輕鬆」， 立意是減少水中拉手的負擔。但深入水把「往下的衝量」傳到身體， 造成下沉、往下推進向量損失、出水阻力反而上升。
  certainty: 🟠
  text: 蝶式入水後的最佳路徑是「橫向滑入水→立刻 outsweep → catch → Insweep」， 身體保持接近水面、波動向前推進。 入水太深時：① 衝量的垂直分量大、身體下沉、出水時要對抗額外向上分量； ② 進入捕水的初始位置太低、無法做出「向後推」的有效角度； ③ Insweep 的推進向量被身體姿勢偏離。 菁英蝶式選手入水深度約 15-25 cm，不是「越深越好」。 「起手輕鬆」是錯誤的感覺指標——應該感覺「水流順著手往後」，不是「水阻小」。
  cross_ref: 入水停頓機制、外划（Outsweep）功能重建
  correct_concept: 入水深度目標約 15-25 cm，手掌入水後接續做 outsweep + catch， 不是繼續往下深入。 感知指標是「身體前進方向的水流順暢」，不是「拉水輕鬆度」。
  perception_impact: 「越深越輕鬆」口令把感知放在「拉水負擔感」， 錯失了「身體與水流前後方向對齊」的關鍵感知。 蝶式真正的省力來自波動連貫，不是減少抓水深度。
```

## 題 39a

**問題**：哪一踢最強：fly.tech.7 🟡「第一踢是多數泳者最具推進力的踢」vs 第二踢命名 Power Kick／Wave Harvest 推進收割（fly.tech.8、fly.err8）；Mason 1992 entry kick 1.9 vs 第二踢+upsweep 2.3。

**原文**：
```
== fly.tech.7
  title: 第一踢（Entry Kick）：波動啟動與推進橋接
  summary: 第一踢在手臂入水時執行，同時啟動波動鏈、填補推進空隙、定位身體深度影響捕水角度，是多數泳者最具推進力的踢。
  certainty: 🟢
  text: 第一踢的時機比值（entry-kick temporal index）與游速呈顯著負相關（r=−0.45）——第一踢越早執行，臂推進期越長，阻力越低；下踢使髖部上浮，協助手臂入水延伸對齊（EVF直接相關）。
  certainty: 🟢
  text: entry-kick temporal index 與游速顯著負相關 r=−0.45；entry-kick 是速度獨立預測因子
  certainty: 🟡
  text: 第一踢是多數泳者最具推進力的踢
  practical_implication: 第一踢時機是可量化的訓練指標，精英訓練已開始量化其相對時機。
```
```
== fly.tech.8
  title: 第二踢（Exit Kick / Power Kick）：推進放大與恢復助力
  summary: 第二踢與 Upsweep 同步，腳踢力與手臂推力疊加，同時抬起髖部抵消出水重心下沉，為空中Recovery提供充分動量。
  certainty: 🔵
  text: 第二踢是在對抗上半身出水重力的唯一踢，缺少它手臂必須靠背肩主動拉出水——是蝶式疲勞和肩傷的最常見機制之一；正確時序讓出水「被彈出去」而非「用力拉出去」。
  certainty: 🟠
  text: 第二踢是把划手推到底、並讓手臂在上方順利完成恢復的那一踢
  practical_implication: 第二踢與出水的同步是最容易被忽略但影響最大的時序問題，疲勞後需優先維持。
```
```
== fly.tech.11
  title: 五個推進加速峰值量化（Mason et al. 1992）
  summary: 精英蝶式選手每週期有五個推進加速峰值，Insweep 最大（4.2 m/s²），依次為第一踢（1.9）、第二踢+Upsweep（2.3）、外划（1.4）；乘波為非主動推進。
  certainty: 🟡
  text: 峰值分布說明蝶式推進來自多個協調節點而非單一動作，各峰值間的時序連接品質決定整體速度。**「五個推進節點 + Insweep 為最大」這個定性結構至今未被推翻**，但具體數字（4.2 / 1.9 / 2.3 / 1.4 m/s²）來自 Mason 1992 單一研究（n 小）、現代影像分析尚未發表同等量化的替代研究，故**具體數值應視為單一研究結果而非定論**——實務上記住「Insweep 是最大、各峰值有時序」即可，不需精確數字。
  certainty: 🟡
  text: 量化五個推進加速峰值：Insweep 4.2 m/s²、Entry Kick 1.9、Outsweep 1.4、第二踢+Upsweep 2.3（屬單一研究，定性順序仍被現代影像支持，具體數字屬歷史參考）
  practical_implication: Insweep 是最大推進相，其品質是訓練的最高優先項。
```
```
== fly.err8
  title: 流線型手臂貼側的海豚踢等同蝶式踢腿訓練
  misconception: 教練讓選手做手臂貼側的流線型海豚踢（aquaman drill / streamline dolphin kick）， 當作蝶腿訓練的主要手段。
  certainty: 🔵
  text: 流線型海豚踢與蝶式踢腿在時機結構上根本不同：流線型只有一種踢的功能，而蝶式有第一踢 （Wave Trigger，波動啟動）和第二踢（Wave Harvest，推進收割）兩種功能完全不對稱的踢。 大量練習流線型海豚踢，並不能直接轉化成正確的兩踢時機。
  certainty: 🟠
  text: 在真正游蝶式時，頭朝下時對應一下踢，頭朝上時對應另一下踢。但在手臂貼側的海豚踢中， 每一下踢都是在頭下壓時發生的——這和蝶式裡兩下踢的時機完全不同。
  cross_ref: 技術分析 參3.1-3.3 兩踢功能不對稱矩陣
  correct_concept: 蝶式訓練中，應盡量讓蝶腿練習保留正確的兩踢時機結構（第一踢配合入水、第二踢配合 upsweep）。 流線型海豚踢是踝關節柔韌度訓練，不是蝶式技術訓練。
  perception_impact: 用流線型海豚踢建立的踢腿感知，缺少「第二踢是要抬起臀部讓手臂飛出去」的功能感—— 當融入全式後，第二踢的力量感和時機感完全無法遷移。
```
```
== fly.tech.6
  title: 兩踢功能高度不對稱：不可混同對待
  summary: 蝶式每划包含兩次功能完全不同的海豚踢，第一踢負責波動啟動與推進橋接，第二踢負責推進放大與恢復助力。
  certainty: 🟠
  text: 兩踢在時機、方向、任務、協調難度上均不同；疲勞時第二踢先崩潰（協調難度最高），第一踢後崩潰；需分別針對性訓練。
  certainty: 🟠
  text: 常見的訓練錯誤是忽略或不重視第二踢——有些泳者為了省力乾脆不踢第二下
  practical_implication: 訓練應明確區分兩踢任務，不用單一踢水口令覆蓋兩者。
```

== fly.err1

  perception_impact: 學員為了「畫出正確形狀」而產生的橫向移動感，會取代「後方推進感」，導致手感目標從 「前臂鎖水→爆發推進」偏移至「手臂移動路徑控制」。

## 題 41a

**問題**：fly.tech.24 已改為「優先順序不能由自由式研究決定」，但 fly.tech.25「第二優先」、tech.26「第三優先」、tech.27「第四／第五優先」仍保留排序（第一優先原是踝）。

**原文**：
```
== fly.tech.24
  title: 踝關節蹠屈柔韌性：蝶式鞭打力學硬體上限
  summary: 踝關節蹠屈會影響蝶式末端推進面的方向，是值得評估的硬體條件；其優先順序與訓練效果不能由自由式相關研究直接決定。
  certainty: 🔵
  text: 踝關節是波動傳遞鏈的末端，蹠屈幅度會影響腳部推進面的方向；把自由式 flutter-kick 的相關結果外推到蝶式屬生物力學綜合推論，McCullough 研究本身未測蝶式或訓練優先順序。
  certainty: 🟡
  text: 女性自由式樣本中，踝蹠屈與 flutter-kick 速度呈中度相關（r=0.509）；蝶式外推尚未由該研究直接驗證。
  practical_implication: 蝶式踢水受限時可把踝蹠屈納入評估，但是否應優先於腿部力量須依個別限制與其他證據判斷。
  cross_ref: 四式踝關節柔韌性結論一致，見 fly.tech.34
```
```

  title: 肩關節活動度：Recovery 低位路徑的硬體前提
  summary: 肩關節活動度是蝶式第二優先解剖能力，活動度不足時被迫走高舉弧線 Recovery（高能耗），並增加肩傷風險。
  certainty: 🔵
  text: 低位 Recovery 需要肩關節能在低位角度完成前向弧線；活動度不足時三角肌被迫主動抬臂代償，快速疲勞；精英選手 Recovery 路徑低位化是近年技術主流趨勢，肩關節活動度訓練受重視程度提升。
  practical_implication: 肩關節活動度評估應在教學蝶式前進行，活動度不足先介入關節訓練再學低位 Recovery。

== fly.tech.26
  title: 胸椎活動度：波動觸發品質的解剖前提
  summary: 胸椎活動度（Thoracic Mobility）是蝶式第三優先解剖能力，不足者胸部下壓起波的幅度與流暢度受限，影響波動觸發品質。
  certainty: 🔵

  practical_implication: 蝶式選手應定期評估胸椎活動度，限制者優先進行胸椎鬆動訓練。

== fly.tech.27
  title: 核心旋轉穩定性與前鋸肌耐力：波動導管與 EVF 硬體前提
  summary: 核心旋轉穩定性（第四優先）是波動傳遞的導管，核心不穩定則波動在腰部耗散；前鋸肌耐力（第五優先）是 EVF 硬體前提，疲勞後肩胛骨失穩導致捕水崩潰。
  certainty: 🟡
  text: 核心穩定性需力量訓練提升；前鋸肌需耐力訓練（非力量訓練）——兩者訓練方式不同，不可混淆；前鋸肌疲勞是蝶式 EVF 崩潰的主要機制。 **「耐力而非力量」這個訓練處方有直接的肌電證據**：蝶式肩部十二條肌肉的肌電圖分析發現，整個划水週期中維持高激活的是**前鋸肌與肩胛下肌**，其餘肌群都是分段作用、有休息空檔。作者據此指出這兩條肌肉特別易疲勞、也特別易受傷。持續激活的肌肉會先輸在耐力上，不是先輸在最大肌力上——這就是為什麼把前鋸肌當力量項目練會練錯方向。
  practical_implication: 陸上訓練應包含前鋸肌耐力專項，而非只做腹肌或核心穩定力量訓練。肩胛下肌與前鋸肌同屬全程高激活，兩者應一併納入耐力課表；蝶式量大的週期若出現肩部症狀，先查這兩條的耐力狀態，再查姿勢角度。
```

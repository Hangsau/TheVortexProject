```
  summary: 髖旋轉幅度直接決定腳掌能否翻轉到位，不足時無論如何指導「腳掌翻出去」都是無效指令——是物理限制而非理解問題。本條的教練觀測把這個旋轉寫成內旋，動作圖譜則把內旋與外旋兩向並列，因為翻腳過程中股骨方位一直在變，兩者可能各自在講不同時點。
```

```
== breast.tech.36
  joint_region: ankle-foot
  nav_zh: 蛙式翻腳
  title: 蛙式翻腳的「腳尖朝外」是四個關節的合成，不是踝關節外翻
  summary: 蛙式翻腳期常被描述為「踝關節外翻、腳尖轉向外側」。解剖學上這句話錯兩層：外翻不發生在踝（距小腿）關節，而「腳尖朝外」也不是任何單一關節的動作，是髖外旋、膝軸向旋轉、距下與橫跗關節旋前四者的合成結果。更關鍵的是——在水中（非承重）無法用肉眼分辨這四者各出了多少。
  certainty: 🔵
  text: 解剖事實：距小腿關節只有一個主要自由度（背屈／蹠屈）。外翻是繞前後軸的額狀面動作，發生在距下關節與橫跗關節。 解剖事實：可能貢獻「腳尖朝外」的四個來源與各自的正常活動度上限——髖外旋，股骨繞縱軸外轉並帶動整條下肢連足一起轉，伸髖位平均約 45 度且個體差異特別大；膝軸向外旋，脛骨相對股骨外旋，只在膝屈曲時存在，部分屈曲時最自由；距下關節旋前，主動外翻約 12.5 度，受外踝與三角韌帶限制；橫跗關節外翻約 10–15 度。 解剖事實：旋前與旋後是單軸三平面運動，外翻、外展、背屈三個成分的組合不變，任一成分存在即代表另兩者也在發生。所以原文分列的「持續背屈」與「外翻」很可能是同一個旋前動作被拆成兩格，不是兩個獨立動作。 泳姿推論：蛙式翻腳期膝處於高度屈曲，因此膝軸向旋轉這個來源在該相位推論上是可用的。上述四個來源在蛙式翻腳中實際各出多少，教科書答不了——那需要游泳運動學量測。 教練應用：把「翻腳」改為分關節描述，並在文件中明講各關節的分配須靠分節段量測、不得目視反推。 尚待實測：水中非承重情境下的目視觀察無法分辨「腳尖朝外」來自髖、膝還是足。教科書描述距下關節的功能是讓小腿能在水平面旋轉而不需要足在地面移動，那是承重情境；蛙式非承重，同一個自由度反過來讓足相對小腿轉動而小腿不必轉。因此個別泳者的限制落在哪個關節，要靠分關節被動與主動測試判定，本條不對此下結論，也不對介入方式下結論。
  certainty: 🟢
  text: 各來源的正常活動度上限——髖外旋於伸髖位平均約 45 度且個體差異大；膝軸向旋轉僅在膝屈曲時存在；距下關節主動外翻約 12.5 度；橫跗關節外翻約 10–15 度。皆為一般人群的關節活動度上限，非蛙式翻腳時的實際使用量。
  practical_implication: 教學語言把「翻腳」改為分關節描述（髖外旋／膝軸向旋轉／距下與橫跗旋前），並註明各關節的分配須靠分節段量測、不得由水中外觀反推。教科書能裁決的是哪些關節有能力貢獻、各自的正常上限多少、哪些成分不可分離；不能裁決實際各出多少。尚待實測：學生翻腳角度不足時，限制落在哪個關節要靠分關節活動度評估判定；在判定之前不預設任何一個關節是限制所在，也不預設任何一種柔軟度介入。
  cross_ref: breast.tech.15（髖內旋是第二關鍵解剖因子）、free.tech.38（踝沒有內外旋，足的三維擺動在距下與橫跗）
```

```
== breast.err4
  title: 「腳跟碰屁股」是正確的收腿口令
  misconception: 幾乎所有初學教學都使用「腳跟碰屁股」作為收腿口令，這個說法已成為蛙式教學的預設語言。
  certainty: 🔵
  text: 「腳跟碰屁股」的幾何路徑必然是往正中間收，造成膝蓋大幅前移（正面截面積激增、阻力最大）， 且腳掌收完朝上，翻腳掌需額外旋轉，錯過最佳蹬水時機。最優路徑是「腳跟往外側臀部靠」—— 髖外旋同時發生，大腿前移量最小，腳掌自然朝向斜後方，可提早進入推進相。

  correct_concept: 「腳跟往外側臀部靠」是物理最優收腿路徑，但這個動作日常生活中幾乎沒有對應動作， 需要刻意感知建立，不能只靠口令替換。
  perception_impact: 錯誤收腿路徑讓學員無法感知「收腿是短暫高阻力階段，需要最快通過」的時間感。 速度谷值管理在感知層無法建立，卡在 L2 無法往 L3 發展。
```

## 題 30

**問題**：Barrowman：breast.tech.18 列 wave style 代表；breast.err16 列 flat style 代表（含 Eddie Reese 教學體系）。教學預設：tech.18「以 wave 為預設」vs err16「早期先建 flat」。

**原文**：
```
== breast.tech.18
  title: Wave Style 波動式：競技主流的最優平衡
  summary: Wave style 是精英蛙式競技主流，肩膀明顯升起但不超過手臂，波動同時達成減阻（收腿傾斜）與推進（俯衝升力）雙重功能。
  certainty: 🟢
  text: 肩膀升起讓收腿在傾斜姿勢進行，膝蓋不直接往前移，正面阻力大幅降低；俯衝角度產生流體升力（物理機制確立，升力在蛙式中的量化貢獻尚未直接測量）；推進效率和收腿減阻的最佳平衡使其成為競技主流。
  certainty: 🟡
  text: wave style 在競技精英中的主流地位觀察
  practical_implication: Adam Peaty、秦海洋、Mike Barrowman 均為 wave style 代表；競技蛙式技術教學應以 wave style 為預設目標風格。
```
```
== breast.err16
  title: 蛙式波動越大越好——wave style 誤套到 flat style 選手
  misconception: 部分教練（受 wave-style 訓練影響）教所有人「蛙式要有大幅波動、髖部要上下擺動」， 立意是建立菁英的 wave style。 但執行端把 flat style 適合的選手（核心穩定/腰柔軟度差/體型較重）也強迫做波動， 他們的波動會變成失控擺動，反而拖慢前進。
  certainty: 🟠
  text: 蛙式有兩大風格體系：① wave style（Adam Peaty、Kosuke Kitajima 等）強調髖部大幅波動， 靠核心連動傳遞推進到上半身；② flat style（Mike Barrowman、Eddie Reese 教學體系）強調身體保持平直， 靠強力推進相+短滑行刻劃距離。兩者都有奧運級代表選手，沒有絕對優劣。 選擇取決於選手特性：腰椎柔軟度、核心控制能力、體型重心、肩柔軟度。 要求所有人都做 wave style 等於要求柔軟度不足者做超出能力範圍的動作， 造成腰椎過度伸展、髖節時序錯亂、整體效率下降。
  correct_concept: 蛙式風格選擇應該按選手特性評估： - 腰椎柔軟+核心強：wave style 適合 - 腰椎硬+核心一般：flat style 適合 - 體型重+短距：flat style 通常較好 教學早期建立平直的 flat style 作為基礎， 等選手進入專項訓練後再評估是否切換到 wave style。
  perception_impact: 「波動越大越好」口令把感知放在「我波動有沒有夠大」的動作監控， 錯失了「推進方向是否向前」這個結構性感知。 強迫波動的選手會感受到「身體上下動但前進感變差」， 但已經被口令鎖死無法調整。
```
```

  certainty: 🟢
  text: 身體保持水平接近水面，雙峰速度曲線波幅最小，推進力方向效率高（水平向前）；收腿時身體水平導致膝蓋前移阻力較高；適合力量強、柔韌性一般的泳者。
```

## 題 31

**問題**：手腳推進能否重疊：breast.err10 correct_concept「必須交替、不能重疊」vs breast.tech.35 Wave 重疊時序、breast.tech.8（Nicol 2022 推進重疊與較低速度變異相關）、breast.err11「允許輕微重疊」。

**原文**：
```
== breast.err10
  title: 手腳可以同時動——同時划同時踢沒有問題
  misconception: 初學者和休閒游者最常出現「手腳同時動」的模式，而且這個模式常因為沒有明確糾正而持續， 甚至有些初階教材沒有清楚說明為什麼不能同步。
  certainty: 🔵
  text: 手腳的推進階段必須交替發生：划手時腳保持流線，踢腳時手保持流線。如果手臂正在划水時 腳在收回，或者腳在踢出時手臂在收回，就等於同時踩油門和踩煞車。手腳協調時序是蛙式效率 最敏感的技術變數之一。
  certainty: 🟠
  text: 划手發生在收腿期間會在你想加速的時候讓你減速；踢腿發生在收手期間也一樣。 原文另指出手腳動作重疊「就像踩了煞車」——本庫把這兩句合併敘述為 「同時踩油門和踩煞車」，油門那半是合併時的措辭，不是原文用字。
  certainty: 🟢
  text: arm-leg coordination 時序與游速的相關性在各項技術指標中最高，是文獻中最有力支持 「時機配合是蛙式效率最敏感變數」的直接證據。
  cross_ref: 手腳時序
  correct_concept: 蛙式的核心原則是「划手時腳保持流線、踢腳時手保持流線」——手腳的推進階段必須交替發生， 不能重疊。
  perception_impact: 手腳同時動時，每個推進的感知都被另一方向的阻力干擾，學員永遠無法感受到「單一推進完整的 速度感」——L3 以上的推進感知建立的前提條件缺失。
```
```
== breast.tech.35

  summary: 蛙式時序不是「對 vs 錯」而是三種策略：Touch-and-Go（短距離極限速度）、Traditional（中距離平衡）、Wave 重疊（長距離節能或菁英衝刺）。教練常用「正確時序」的口令，但實際是依距離 / 體型 / 風格選擇——把一種時序當作普遍正確會限制選手潛能。
```

```
  summary: 蛙式時序不是「對 vs 錯」而是三種策略：Touch-and-Go（短距離極限速度）、Traditional（中距離平衡）、Wave 重疊（長距離節能或菁英衝刺）。教練常用「正確時序」的口令，但實際是依距離 / 體型 / 風格選擇——把一種時序當作普遍正確會限制選手潛能。
  certainty: 🟠
  text: 三種時序策略的差異點： - **Touch-and-Go**（觸碰即起）：手前伸到底「碰一下」就立刻收手做下一划，幾乎沒有 streamline 滑行。SR 最高、SL 最短、能量代價最高，適合 50m 衝刺。Adam Peaty 為代表。 - **Traditional**（傳統分段）：手前伸 + 短滑行 + 收手；明確的「拉手→踢腿→滑行→拉手」分段。SR 中、SL 中、平衡推進與節能，適合 100m。 - **Wave 重疊**（waveform overlap）：拉手末段就開始收腿、踢腿時手已開始下一划外划；推進相互重疊。SR 高、SL 中、coupling 動能最大。Kosuke Kitajima、Lilly King 為代表，適合 100/200m 衝刺。 選擇依個人體型（重心、肩柔軟度、髖內旋）、訓練史、距離綜合決定，不是「先進」優於「傳統」。
```

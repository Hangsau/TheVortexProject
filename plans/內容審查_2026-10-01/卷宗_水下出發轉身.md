## 題 42

```
== udk.tech.1

  summary: 出發與轉身後水下速度通常高於水面游泳速度，UDK 讓泳者留在高速區間更長時間。

  text: 水面游泳受波浪阻力影響，水下無此阻力；出發/轉身後初始速度遠高於游泳速度，水下可延長這個高速區間。
```

```
== udk.err9
  title: 水下踢越遠越好，15 公尺上限就是目標

  certainty: 🟢
```

## 題 43

**問題**：起踢時機：udk.err8「離牆後盡快起踢」vs udk.tech.17「推牆速度高時先滑到交叉速度再踢」。

**原文**：
```
== udk.err8
  title: 轉身後必須先滑行，等速度降下來再開始踢腿
  misconception: 教練常指導「推牆後先滑行維持流線型，等速度降下來再開始踢腿」， 認為干擾流線型滑行會浪費初始動能。
  certainty: 🟠
  text: 選手在流線型滑行時速度下降得非常快。彎膝準備第一下踢的減速量，不管在什麼時間點發生都差不多—— 等越久，只是在從更慢的速度開始加速而已。近年一份運動生物力學的力學模型也指向同一方向： 多數受試菁英泳者的最優轉換速度高於其等速游泳速度，支持盡早起踢的邏輯 （該研究樣本為 10 名菁英女性、在水槽 tethered 條件下量測淨力，作者自述為 conceptual model， 不宜讀成賽場實證，2026-09-04 更正原文「研究也確認」的定論語氣）。
  certainty: 🟠
  text: 以精英選手 Aaron Greenberg（自由式）測試：立刻起踢比短暫滑行快 0.1 秒， 比長時間滑行快 0.18 秒（5 公尺成績）。同篇另測仰式選手 Amy Bilquist， 立刻下踢比短滑行快 0.1 秒、長滑行則慢 0.16 秒。
  certainty: 🟠
  text: 選手在流線型滑行時速度下降得非常快。彎膝準備第一下踢的減速量，不管在什麼時間點發生都差不多。 等越久，就只是在從更慢的速度開始加速而已。
  certainty: 🟢
  text: 以冪律擬合流線滑行（SL）／海豚踢（DK）／自由式（FC）三者的淨力–流速曲線， 交會速度 USL-DK 與 UDK-FC 即最佳轉換時機；對多數受試者而言這兩個交會速度 **高於**其各自的等速游泳速度（VDK_const、VFC_const），支持盡早起踢的邏輯。 樣本為 10 名菁英女性泳者、水槽 tethered 淨力量測，作者提出的是 conceptual model。

  correct_concept: 轉身後，第一下上踢應在離牆後盡快啟動，而非等待滑行。目標是最小化從推牆到第一踢之間的速度損失窗口。 注意：出發起跳後的水下情境略有不同，入水瞬間需要建立流線型姿勢，有一個短暫的身體整合窗口。
```

```
== udk.tech.17
  title: UDK 起踢規則——滑到個人滑行／海豚踢交叉速度就開始踢
  summary: 推牆後速度高於個人「流線滑行—海豚踢」淨力交叉速度時保持流線；速度降到交叉點就開始UDK。若離牆後已接近或低於交叉速度，直接起踢。群體研究的實用起點約1.9–2.2 m/s，精英泳者應以個人力—速度曲線校準。
  certainty: 🟢

  certainty: 🟠
  text: 精英選手實測：自由式 Aaron Greenberg 立刻起踢比短暫滑行快 0.1 秒、比長時間滑行快 0.18 秒（5 公尺）；仰式 Amy Bilquist 立刻下踢比短滑行快 0.1 秒，長滑行則慢 0.16 秒
  certainty: 🟢
  text: 建立「流線型滑行 → UDK → 出水划手」三狀態最優轉換速度模型，確認大多數精英選手最優起踢速度高於水面游泳速度
  certainty: 🟢
  text: 16名有經驗男子泳者的拖曳測試得到1.9–2.2 m/s的群體最佳起踢速度區間。
  practical_implication: - **有速度計／牽引量測**：建立個人流線、UDK與水面泳的淨力—速度曲線，在SL–DK交點起踢、DK–水面泳交點breakout。 - **沒有儀器**：以1.9–2.2 m/s作第一起點，拍攝立即、短滑、長滑三種5m／10m測試；選擇速度最低點最高且10m最快的版本。 - **推牆弱或第一踢能力強，離牆後很快落到交點**：直接或極短滑行後起踢。 - **推牆速度高、流線阻力低，過早踢會增加主動阻力**：先滑到交點再踢。
```

```
== udk.err1
  title: 踢的幅度越大，推進力越強
```

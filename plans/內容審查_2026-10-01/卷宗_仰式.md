## 題 24

**問題**：back.err7 說「想呼吸就呼吸、不用管節律」是誤區、要固定節律；back.err14 說「強迫固定節律」是誤區、應自然按需。兩條如何並存或擇一？

**原文**：
```
== back.err7
  title: 仰式臉在水面上，想呼吸就呼吸、不用管節律
  misconception: 因為仰式臉多半在水面上，教練常直接說「仰式不用練呼吸，想換氣就換氣」， 把呼吸節律從教學中省略。這是「主動省略」而非沒注意到——口令明確告訴學員呼吸不重要。
  certainty: 🔵
  text: 沒有外在水的威脅不等於呼吸可以隨意。無節律呼吸最常見的後果是憋氣： 憋氣使二氧化碳累積、肌肉快速疲勞，初學兒童尤其常一路憋到牆邊才大口喘。 規律呼吸（一手划入水吸、對側手划入水吐）同時穩定頭部、串接手腿時序、降低整體張力。
  certainty: 🟠
  text: 多家教學指引一致建議仰式採固定呼吸節律：一臂划水吸氣、對臂划水吐氣，以避免憋氣與疲勞， 並協助手腿協調與放鬆。兒童憋氣是教練需主動辨識並糾正的常見問題。
  cross_ref: 頭部基礎位置、化學受器與呼吸驅動
  correct_concept: 仰式仍需固定呼吸節律。感知目標是「吐氣與某一側划手綁定」形成自動節奏， 而非用意識決定何時呼吸。節律穩定後，呼吸成為手腿時序的節拍器。
  perception_impact: 「想呼吸就呼吸」使學員在用力時下意識憋氣，胸腔張力升高遮蔽全身水感（C 型）； 失去呼吸作為節拍錨點後，手腿節律也更難整合。
```
```
== back.err14
  title: 仰式也要套自由式呼吸節律——每三划換氣、強迫節律
  misconception: 部分教練把自由式 bilateral breathing 的「每三划換氣」思維直接套到仰式： 要求學員「每幾下換一次氣」。立意是建立穩定節律，但仰式臉本來就在水面上， 強迫節律反而把自然的呼吸打亂、製造緊張。
  certainty: 🔵
  text: 仰式臉持續在水面上（除浪較大或速度時水濺臉），呼吸不受換氣時機限制，本質上接近陸上呼吸。 強迫節律相當於要求選手「每跑三步換氣一次」——把自由呼吸改成固定週期， 會讓選手在「該換氣的節律點」感到憋氣、在「不該換氣的節律點」感到不知道要不要呼吸。 結果是核心張力上升、整體放鬆度下降，反而拖累技術。 與自由式相反——自由式臉在水中需要建立節律，仰式臉在水面不需要也不該。
  cross_ref: 頭部基礎位置、仰式臉在水面上，想呼吸就呼吸、不用管節律
  correct_concept: 仰式呼吸應該保持「自然、按需」——感覺需要時呼吸，不需要強迫節律。 如果泳者因緊張而憋氣，介入點是放鬆而不是節律。 例外：水濺臉的開放水域或衝刺時，可以建立「划手週期內的吐氣時機」避免嗆水， 但這是技術應對特定情境，不是統一節律規定。
  perception_impact: 強迫節律把感知頻寬鎖在「我下一次換氣時機」的計時監控上， 把該用於水壓回饋的注意力擠掉。 放鬆呼吸恢復後，感知層的水感訊號才能浮上來。
```

## 題 25

**問題**：back.err4 correct_concept「肩部主導…強調入水後肩膀壓低」vs back.tech.6／back.err1「把肩膀壓下去是錯誤感知目標，應主動抬高回臂側肩」。

**原文**：
```
== back.err4
  title: 滾轉要靠髖部（或肩部）主導，選定一邊才對
  misconception: 教練常將仰式滾轉二分為「髖部主導」或「肩部主導」，並要求學員固定採用其中一種。 告訴學員「用髖帶動」後，大多數人對髖部動作感知很弱，往往變成腰部扭動代償。
  certainty: 🟢
  text: Gonjo 等人（2021）在四種強度下量到：仰式的肩滾轉、髖滾轉與全身滾轉幅度不隨強度縮小， 自由式則全面縮小。所以「游快一點就少轉一點」在仰式沒有依據。 「由什麼主導」實際上取決於每一划當下的速度、踢水相位以及手掌抓水是否成功， 並非固定模式。髖部主導與肩部主導各有適用情境：前者適合踢水有力的長距離選手， 後者適合踢水較弱或短距離提升划頻的情境（🔵 這一組配對是依推進來源推導的， 文獻只量到「幅度不隨強度縮小」，沒有比較過主導方式與距離專項的搭配）。
  certainty: 🟢
  text: 四種強度（最大速度的 83–100%）下，仰式的肩滾轉、髖滾轉與全身滾轉幅度維持不變， 自由式則全面縮小。原文量的是強度不是比賽距離，且浮力矩造成的那一部分滾轉（WBRBT） 在仰式也是顯著縮小的——可支持的是「速度不是縮小滾轉的理由」， 不是「仰式滾轉完全不受速度影響」。
  cross_ref: 競技仰式泳者肩旋轉與髖旋轉的現代運動學數據、仰式在不同速度下維持旋轉幅度（不像自由式縮小）、仰式旋轉的不對稱性
  correct_concept: 滾轉主導方式應依選手踢水能力與比賽距離判斷，不強制單一模式。 有效教學路徑：髖部主導從踢水訓練切入，讓腿打水節律帶動身體旋轉； 肩部主導從入水動作切入，強調「入水後肩膀壓低」的感知目標。
  perception_impact: 「用髖帶動」指令常觸發腰部扭動代償，旋轉感知與推進感知脫節； 身體晃動而手掌未能固定水中錨點，感知系統失去旋轉與推進力連動的訊號。
```
```
== back.tech.6
  title: 仰式旋轉的不對稱性：回臂側主動上抬，划水側被動深沉
  summary: 仰式的身體旋轉不是兩側對稱地旋轉 45°，而是回臂側向上主動用力、划水側被動深沉的單側主動模式。
  certainty: 🔵
  text: 回臂側肩膀（recovering shoulder）大幅向上 forward roll，盡量高出水面；這個向上動作把對側肩膀壓得更深入水下，進入更有力的生物力學位置。划水側的深沉是自然結果，不需要主動下壓。
  practical_implication: 「把肩膀壓下去划水」是錯誤的感知目標；正確感知是「把回臂側肩膀盡量抬高」，划水側深沉是自然結果。兩者產生相同外觀，但主動用力方向相反。
```
```
== back.err1
  title: 仰式要躺平，旋轉是不穩定的信號
  misconception: 許多教練為修正初學者「過度扭腰」，改用全面壓制旋轉的指令：「游仰式要躺平，不要扭來扭去。」 結果是把矯正過度旋轉的口令，變成一條消滅正常旋轉的指令。
  certainty: 🟢
  text: 競技男性泳者的仰式最大肩滾轉平均 49.73 ± 5.73°（Gonjo 等人 2020，十名男性競技泳者， 最大速度），也就是說「幾十度的滾轉」是這個族群的常態，不是個別選手的怪癖。 旋轉使背闊肌進入最佳收縮起始長度，是仰式推進力的核心機制之一（🔵 肌肉最適預拉原理）。 Gonjo 等人 2021 進一步在四種強度下量：自由式的滾轉幅度隨強度上升而全面縮小， 仰式則維持——所以「衝刺縮小旋轉提高划頻」的策略在仰式不適用。
  certainty: 🟢
  text: 三維運動學實測：十名男性競技泳者的仰式最大肩滾轉平均 49.73 ± 5.73°、 最大髖滾轉 39.83 ± 7.25°。受試者是 competitive 不是 elite，本條不寫「精英」。
  certainty: 🟢
  text: 四種強度（最大速度的 83–100%）下，自由式的全身滾轉、肩滾轉、髖滾轉幅度全部隨強度縮小， 仰式則維持不變；速度增加不應成為縮小旋轉的理由。原文有一個限制常被略過： 浮力矩造成的那一部分滾轉（WBRBT）在仰式也是顯著縮小的， 所以「仰式旋轉完全不受速度影響」講得太滿。
  certainty: 🟠
  text: 正確的感知目標是「回臂側肩膀盡量向上抬高」，划水側的深沉是自然結果，不需主動下壓。 兩者外觀相似，但主動用力方向完全不同。
  cross_ref: 技術分析 §旋轉機制
  correct_concept: 仰式需要充分旋轉才能讓背闊肌進入最佳預拉位置，正確感知目標是「回臂側肩膀主動上抬」， 而非對稱壓制兩側旋轉。
  perception_impact: 「躺平」指令使學員用全身張力維持水平姿態，背闊肌無法進入預拉位置，划水只靠小肌群， 手感與水感回饋隨之弱化；張力升高後感知訊號被整體遮蔽。
```

## 題 27

**問題**：back.tech.12「推至大腿側、充分推至髖部、完整推至大腿側是可觀察指標」vs back.err12「拉到大腿側是誤區、通過臀部就釋放」、back.err6「從肩掃到大腿」誤區。

**原文**：
```
== back.tech.12
  title: 推水：手臂加速推至大腿側，指尖朝向池底，充分伸展至髖部
  summary: 推水相為阻力推進主導，手臂加速推至大腿側，指尖朝池底，單次划手最大推力輸出點。
  certainty: 🔵
  text: 阻力推進主導（阻力 F = ½ρv²CdA），手臂加速使水流相對速度增加，最大化阻力推進。充分推至髖部才完成有效推水，提前收手浪費末段推力。
  practical_implication: 「不是推水，是拉身體過去」的感知重建有助避免手臂直線划水；完整推至大腿側是確保推水充分的可觀察指標。
```
```
== back.err12
  title: 划水要拉到大腿底——過度延長拉水反被減速期反咬
  misconception: 常見口令「拉到底」「划到大腿側」要求把水下划水延長到最遠。 立意是「划程越長推進越多」，但忽略了拉水的力學是有「最佳出水時機」的， 過了臀部之後手在水中變成阻力源而非推進源。
  certainty: 🟠
  text: 拉水的有效推進區結束於手掌通過臀部側面附近（約 6 點鐘到 7-8 點鐘位置）。 過了這個點之後，手繼續向後推時水流方向已經與身體前進方向夾角太大， 推進力分量下降但阻力分量上升；同時這段時間還佔用了「應該開始準備回臂」的窗口， 讓回臂被迫加速來補時序，整個 stroke rate 受損。 菁英選手出水點通常在大腿外側偏上而非大腿底——這是力學最佳化的結果，不是肌力不足。
  certainty: 🟠
  text: 水下高速攝影分析菁英仰式選手出水時機，多數在手通過臀部後 0.05-0.1 秒內出水， 而非繼續拉到大腿底。
  cross_ref: 推水、拉水
  correct_concept: 拉水的目標是「通過臀部時釋放」，不是「拉到底」。 感知目標是「手通過臀部時感覺水壓開始下降→立刻出水」， 不是「主動把手推到大腿底再出水」。
  perception_impact: 強迫拉到底會讓泳者錯過手部水壓回饋的轉折點訊號（從推進變阻力的那一瞬）， 把感知從「水壓何時最強」轉移到「手有沒有到大腿」的位置監控。
```
```
== back.err6
  title: 划手手臂打直，從肩掃到大腿
  misconception: 初學教學常用「手臂打直，從肩膀一路掃到大腿」作為划手口令——直臂划水好教、好示範， 被當成標準動作教給入門者，而非過渡階段。問題是它把「容易教」誤當成「正確」。
  certainty: 🟠
  text: 直臂划水時手腕成為手臂最深點，前臂無法在肩前方建立向後的推進面，推水時間窗大幅縮短； 彎臂（高肘 / 深肘抓水）讓前臂提早朝後施力，推水路徑更長。 Race Club 等教學分析比較彎臂與直臂，指出彎臂在划速與推進加速度上明顯較優； 但具體百分比來自教學影片分析，未追溯到同儕審查原始數據，不引用為精確值。 直臂並非全錯——休閒泳者與旋轉不足者直臂較易學，且直臂常是「兩側旋轉不對稱」的徵兆而非根因。
  certainty: 🟠
  text: 彎臂（bent-arm / deep-elbow catch）划水的推進力與加速度高於直臂，是精英仰式的主流選擇； 直臂多見於休閒與入門泳者。
  cross_ref: 教學誤區 §back.err3（深度與肘位）
  correct_concept: 彎臂與直臂是光譜，不是對錯二分。入門可從直臂建立節律，但要儘早過渡到「肘部彎曲、前臂朝後」的抓水； 關鍵感知是「前臂背側壓到水」，不是「手臂掃過多長的弧」。直臂若源於旋轉不足，要先修旋轉而非只改手臂。
  perception_impact: 直臂划水時前臂無法承接水壓，學員只感覺到手掌劃過水面下的「滑」，建立不起前臂捕水感（A 型手感缺失）； 把注意力放在「手臂掃多遠」的空間描述，而非掌心與前臂的水壓回饋。
```

## 題 28

**問題**：捕水肘角：back.err3 🟠「捕水完成肘部角度約 100–120°」vs back.tech.11 🟢「肘部維持屈曲 90–100°」。

**原文**：
```
== back.err3
  title: 手伸越深，抓到的水越多，推力越大
  misconception: 常見教法是「手伸越深，抓到的水越多，推力越大」。力學上這個邏輯並非全錯（更深手位確實可增加某些力矩）， 但忽略了深抓帶來的三個代價，且「深抓」一詞本身存在嚴重的用詞混淆。
```

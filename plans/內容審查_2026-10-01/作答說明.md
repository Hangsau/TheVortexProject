# 三方辯論作答說明（MiniMax-M3／Sonnet／Opus 共用）

背景：The Vortex Project 是一個游泳教學知識庫（canonical YAML，公開層會上網站）。審查發現多組條目互相矛盾
或含明顯錯誤。你是三位獨立審查者之一，另兩位看不到你的答案。最後由 Opus 綜合裁決，再改資料。

確定性標記：🔵 物理／解剖推導（不需來源）、🟢 近期文獻、🟡 舊文獻、🟠 教練觀測、🔴 待查／個人假設。

## 每題請依這個格式作答

```
### 題 <編號>
- 判斷：A 對／B 對／兩者可並存（寫出成立條件）／兩者都有問題
- 理由：2–5 句。物理或解剖推導寫清楚推導步驟。
- 建議改法：指明「條目 ID ＋ 欄位」，給可直接替換的繁體中文句子（保留原文其他部分）。不需要改的寫「不改」。
- 確定性標記建議：該句應標 🔵／🟢／🟡／🟠／🔴，為什麼。
- 信心：高／中／低
- 待查證事實：列出你的判斷依賴、但你無法第一手確認的外部事實（研究內容、規則條文、人物歸屬）。
```

## 鐵則（違反＝該題作廢）

1. **不准捏造**研究、作者、年份、數字、規則條號。不確定就寫「待查證」，不要給一個看起來精確的值。
2. 原文沒寫的數字，不要寫進「建議改法」。需要數字時寫「〔待查證後填入〕」。
3. 寧可建議「刪掉無來源的具體數字、保留定性結論」，也不要用另一個無來源的數字取代。
4. 「兩者可並存」只在你能寫出**具體的成立條件**（族群、距離、相位、量測定義不同）時才選；不能拿來逃避判斷。
5. 繁體中文、精簡，不寫開場白與總結。
